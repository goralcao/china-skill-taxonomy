前测 · 日记的格式和选材

三道题都有唯一答案，答错会告诉你错在哪。

单选题1. 日记开头先要写清哪两样？

A日期和天气
B题目和字数
C姓名和班级

单选题2. 一天里发生了很多事，日记该写几件？

A从早到晚全写
B只挑一件，把它写清楚
C至少写五件

单选题3. 「然后……然后……然后……」这种写法，问题出在哪？

A标点太少
B字数不够
C一路「然后」到底，成了流水账

起意 · 一天 24 小时，日记只写几件？

一天发生的事太多，日记只挑一件。先「撒」：8 张生活卡随便点进素材池；再「收」：只留 1 张进主格。

最后点 3 个「我还要写的词」。点哪张都行，不判好坏——空输入框等于把构思难题原样退回给你。

撒

8 张卡进池

先有的可想。

收

1 张进主格

只写这一件。

词

点 3 个词

起草时用得上。

早上 7:30 被闹钟叫醒
早餐时把牛奶洒了
课间同桌借我橡皮
体育课跑了 50 米
午饭吃到一颗很酸的葡萄
放学下雨，伞偏向同桌
晚上帮妈妈择菜
睡前读了两页书
湿了一路 没发现 讲笑话 书包 干的 悄悄
花 10 分钟把 8 张卡翻一遍：先随便点进素材池，再收 1 张进主格，最后点 3 个「我还要写的词」。
素材池 0 张 · 主格 0 / 1 张 · 想写的词 0 / 3（不判好坏）

搭骨架 · 三格，每格都给它一个任务

给三格事件条排顺序，每格填一句「这段要让人知道___」，再点一下详还是略。

这里只报「三格功能填了几格、详略点了几格」，不判好坏，填不完整也能往下走。

  • 每格填一句功能，让三段各有任务；别一路「然后……然后……」到底。
  • 事件条可以上移调顺序，调完把三段头一句连起来读一遍。
  • 详的那段多写几行，略的一段带过；详略点一下就行，不用写理由。
↑ 上移放学时雨下得很急，我和同桌一起走详略
↑ 上移我把伞往他那边挪，自己肩膀湿了详略
↑ 上移到家发现作业本倒是干的详略
每格都填一句「这段要让人知道___」，再点一下详略。事件条可以上移调顺序，别一路「然后」到底。
三格功能 0 / 3 · 详略 0 / 3（不判好坏）

连一连 · 日记的格式，各自管什么

左边是日记里的做法，右边是它管的事。连完不用交卷，只看自己能不能说清「为什么」。

中测一 · 构思不能只给一个输入框

三道题都有唯一答案，重点看「先撒后收」和「每格有任务」。

单选题1. 8 张生活卡点了一堆进素材池，下一步该做什么？

A只收 1 张进主格当主线
B全部写进正文
C按卡片大小排序

单选题2. 搭骨架时，每格都要填「这段要让人知道___」，是为了？

A凑够字数
B让每段有个任务，别一路「然后」到底
C让字写得好看

单选题3. 起草分三格，每格顶上那句「这格写什么」是？

A要抄下来的范文
B必须照着写的格式
C一句提示，帮你别写跑题

起草 · 先定格式，再分三格写

日期、天气做成填空条前置锁定；三格各顶一句「这格写什么」，写多写少都行。

这里只判写没写，不判好坏。先写后看范文——这一页没有范文，也没有好词好句库。

格式条

日期 + 天气

先定下来。

三格

开头 / 经过 / 结尾

各写各的。

存本

写没写看得出

好坏不打分。

先填日期和天气，把日记的格式定下来；没填也照样能写（不拦路）。
第一格 · 开头：什么时候、在哪儿
第二格 · 经过：最要紧的那一步（详）
第三格 · 结尾：后来怎么样了（略）
三格写了 0 / 3 行（只判写没写，不判好坏）。这里没有范文。

改 · 按体检单，改的是句子

先点右边一条体检项，全文会高亮可疑句；再点左边一句，才算记下一处改动。增删改调换，不给分数。

已改 0 / 5 处（改的是句子，不是错别字） 先自己试一次，再看老师改这一句

红删、绿增、蓝调；错别字不在这张单子上

  • 点清单只算看到问题，点中句子才算改过；改完左右对照。
  • 能给学生看的只有事实：这个词出现 3 次、这段有两句「我」开头。
  • 不判情感、不判立意、不查好词好句；字数也只说「还差 X 字」。

出刊 · 我的一页书

把三格拼成一页，署上自己的名字，对着三条标准自查，再点「发布」。勾不满也能出刊。

顺手把四个易错点看一遍：别把流水账当日记，别把好词好句库挂在输入框旁，别先发范文再说照着写，也别把改错别字当成「改」。

① 一件事

这一段只讲一件

不跑题。

② 都相关

每句都跟它有关

不掺水。

③ 能听懂

读一遍给别人

不打分。

（还没起草。回到「起草」那一页写三格，它就会出现在这页书上。）
① 这一段只讲一件事 ② 每句话都跟这件事有关 ③ 我读一遍，别人能听懂
三条只问「这一段清楚吗」，不问「写得好不好」——勾不满也照样能出刊。

这一页没有分数，也没有排行榜。机器能说的是「事实」：字数、句数、这个词出现几次；「写得好不好」由你自己读一遍说了算。

后测 · 五道题，把写作的边界说清楚

增 删 调 换
▼

能给学生看的是「这个词出现 3 次」，不能给的是情感、立意评分。

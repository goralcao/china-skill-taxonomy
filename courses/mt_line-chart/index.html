一周气温从 18℃ 升到 26℃，哪天升得最快？

五年级数学 · 折线统计图

点看多少 线看变化 陡就是变化快

先答三道，凭感觉

三道题都在问「折线图比条形图多给了什么」。

单选题1. 想知道一周里哪天最高、哪天最低，看折线图的什么最方便？

A各个点的高低
B横轴的字
C线的颜色

单选题2. 折线图上一段线往上走，说明数量在怎么变？

A变少
B不变
C变多

单选题3. 要看出「气温一路怎么变」，哪种图更合适？

A条形图
B折线统计图
C统计表

7:30 测一次，一周的点怎么连成线？

连续 7 天，每天 7:30 测一次气温：18、20、19、23、26、24、21℃。把每天的数值在图上点一个点，再按日期先后连起来，就是折线统计图。

点看「多少」，线看「怎么变」。周四的点在 23℃，说明那天 23℃；周三到周四那段线向上抬，说明气温升高了。

条形图用柱子比大小，折线图多给了一样东西：变化的方向和快慢。

一个点

周四 · 23℃

横轴找日期，纵轴找数值。

一段线

19℃ → 23℃

线往上，数值增加。

最高点

周五 · 26℃

整周里数值最大的那天。

读折线图先看点：点的位置 = 那天的数量；再看线：线的走向 = 数量的变化。

上升、持平、下降，线会自己说话

线往上走是增加，走平是不变，往下走是减少。同样往上升，线越陡，变化越大。

周三 19℃ 到周四 23℃ 升了 4℃，线明显比周一到周二（升 2℃）更陡；所以「哪天升得最快」看的就是最陡的那一段。

  • 找点：先看横轴日期，再看纵轴数值
  • 看段：比较相邻两天的差，判断升还是降
  • 比陡：同样时间里差得越多，线越陡
  • 说趋势：用「先升后降」「持续上升」这类词概括
判断变化快慢不能只看点的高低，要看相邻两点的差：差越大、线越陡，变化越快。

这条线，说的是哪句话

左边是折线上的样子，右边是它的含义。把相配的连起来。

画一张折线图，还要会选图

画图三步：描点 → 标数 → 依次连线。先在横轴找到日期、纵轴找到数值点上去，在点旁写清数，最后按日期先后连起来。

选图看目的：比谁多谁少用条形图，看增减趋势用折线图。一周气温、成绩变化、体温记录这类「随时间变」的数据，最适合折线图。

第 1 步

描点

横轴日期 + 纵轴数值，交叉处点一个点。

第 2 步

标数

点旁写具体数，别让人去猜刻度。

第 3 步

连线

按时间先后依次连，不能跳着连。

折线图的强项是「变」：数据随时间增减、想看趋势或预测走向，就选它。

改一天的数据，看折线怎么变

点画布选中某一天，用「升高 / 降低」改它的数值，折线和右侧的趋势结论会立刻重画。

一周气温 · 选中周一 18℃ 点画布选一天

折线随数据实时重绘：点的高低、线的陡缓都在变

  • 选中哪一天，竖虚线就停在哪一天，右侧会算出它比前一天多还是少。
  • 把某天抬高，那一段线会变陡；「升高最快的一天」也可能跟着换。
  • 最高点、最低点、整体趋势都随数据变，读图要按新数据重新判断。

中测二 · 趋势与选图

这一组要会概括整条线。

单选题1. 一周气温 18、20、19、23、26、24、21℃，整体趋势怎么概括？

A先升后降
B一直上升
C一直下降

单选题2. 想比较五个班各有多少人，选哪种图更合适？

A折线统计图
B条形统计图
C两种都一样

单选题3. 同一段时间内，哪段折线最陡，说明什么？

A那天数量最小
B那天数量最大
C那段时间变化最快

四个易错点，都在「点」和「线」之间

折线统计图最容易错的地方，是把点的高低当成变化快慢：点高只说明那天数值大，变化快慢要看相邻两点的差。

坑一：看高低判快慢

周五 26℃ 最高 → 升得最快 ✗

周五虽最高，但比周四只升 3℃；周三→周四升 4℃ 才最陡。

坑二：折线当条形读

只看柱子比大小 ✗

折线图的价值在线段的升降，别只比谁高谁低。

坑三：连线跳着连

按大小排序再连 ✗

必须按日期先后依次连，跳着连趋势就全反了。

坑四：纵轴刻度不看

陡就一定差得多 ✗

纵轴每格代表多少要先看清，同一格数在不同刻度下差不同。

一句话：点读数量、线读变化、陡读快慢；画之前先看清横轴和纵轴各表示什么。

回到开头那周气温：周三 19℃ → 周四 23℃ 升 4℃，周四 23℃ → 周五 26℃ 升 3℃，所以最陡的是周三到周四，升得最快的是周四；最高点却是周五。

这一课，装进四张卡

1
点读数量
周四的点 → 23℃
▼

横轴找日期，纵轴找数值。

最高点、最低点直接看出极值。

2
线读变化
向上增 · 水平平 · 向下减
▼

相邻两点比较才有「变化」。

别把点的高低当成变化快慢。

3
陡读快慢
差越大，线越陡
▼

先看清纵轴每格代表多少。

最陡的一段就是变化最快的一段时间。

4
画与选
描点 → 标数 → 连线
▼

按时间先后依次连，不能跳着连。

比大小用条形，看趋势用折线。

下次看折线图，先问两句：「这个点是多少？」和「这段线比上一段陡还是缓？」一句读数量，一句读变化，趋势就藏在这两句里。

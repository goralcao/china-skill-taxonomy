186 + 97 + 214，怎么算才不列竖式

口算比赛只给 1 分钟，谁先把三个班的捐书总数报出来，谁赢。三个数是 186、97、214。

照着顺序来：186 + 97 = 283，个位 6 + 7 要进位；再 283 + 214 = 497，又要进位。两次都得在脑子里记，慢。

换个眼：186 + 214 正好 400，一个零头都没有；再加 97，400 + 97 = 497，几乎不用算。

从前往后

186 + 97 = 283 283 + 214 = 497

两次进位，脑子里要存一个中间数。

先凑整百

186 + 214 = 400 400 + 97 = 497

第一次就凑成整百，后面一眼出。

凭什么能换

186 + 97 + 214 = 186 + 214 + 97

凭加法有交换律。下一节说清楚。

总数一样，只是先算谁变了。这一课就是把「能怎么换、为什么能换」说清楚。

两个数换位置，和一分不少

两条彩条拼起来还是那么长。数字换位置，长条一点没变，所以和也不变。

这条规矩叫加法交换律：两个数相加，交换加数的位置，和不变。

  • 186 + 214 = 214 + 186 = 400　两边完全相等，不是「差不多」。
  • 减法不行：10 − 3 = 7，可 3 − 10 连减都不够减。能换位置的只有加法（乘法也行）。
  • 用处：把「好算的那一对」挪到前面，先算出整百，剩下的就轻松了。
换的是整个数，不是它的某一位。186 搬过去还是 186，不能搬成 168。

连一连：这个算式可以写成什么样

左边每个算式，右边都有唯一一个「换了位置但结果一样」的写法。点左边一项，再点右边一项。

三个数相加，先捆哪两个都一样

三个数相加，可以先把前两个相加，也可以先把后两个相加。括号画在哪一对上，只是先算谁的记号。

这条叫加法结合律。两条合起来用，三个数怎么排、怎么捆都随你，结果钉死在 497。

  • ① 交换律：a + b = b + a　—— 两个数换位置。
  • ② 结合律：(a + b) + c = a + (b + c)　—— 三个数换捆法。
  • ③ 凑整口诀：先看个位，哪两个的个位加起来是 10，就把它们挪到一起。
换之前先算一笔小账：换成哪一对，能凑出整十或整百？凑得出来的那一对，就是该先算的。

点两张数字卡，交换位置，看和变不变

先点一张卡选中它，再点另一张，两张就互换。右上角的和从头到尾不会动，变的只有中间的算法。

四个坑，第一个最常见

① 把交换律用到减法上

✗ 40 − 15 写成 15 − 40

能换位置的只有加法和乘法。减法换了，答案连正负都变了。

② 搬家搬错了数

✗ 186 + 97 + 214 = 186 + 214 + 79

换的是整个数。97 挪过去还是 97，不是 79。抄错一位，和就差了 18。

③ 只会换，不会凑

✗ 186 + 214 + 97 → 214 + 186 + 97

换了等于没换，第一步还是要进位。换的目的是凑整，不是练手速。

④ 硬凑整，把数拆散

✗ 97 想凑 100，从 214 里借 3

214 一拆就变成 211 和 3，三个数变四个数，越算越乱。凑整是找现成的一对，不是硬借。

换之前问自己三句：这几个都是加法吗？整个数搬对了吗？搬完能凑出整百吗？

回到捐书：186 + 97 + 214。三个数全是加法 → 把 214 挪到 97 前面 → 186 + 214 = 400，400 + 97 = 497。中间一次进位都没有。

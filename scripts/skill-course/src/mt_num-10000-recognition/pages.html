从一数到一万

10 个一是十，10 个十是百，10 个百是千，10 个千是万。

数位顺序：个、十、百、千、万，满十就向前一位进一。

10 个一

= 1 个十

满十进一

10 个百

= 1 个千

1000

10 个千

= 1 个万

10000

数位从右往左是个十百千万，满十进一。

读写万以内的数

3250：千位 3、百位 2、十位 5、个位 0，读作三千二百五十。

中间或末尾有 0 时，0 要写出来占位，但读法有讲究。

  • 从高位读起。
  • 中间有 0 读「零」，末尾的 0 不读。
  • 哪一位上一个单位也没有，就写 0 占位。
读写都从高位起，空位写 0 占位。

四处容易认错

万以内数最容易错在这四处。

数位顺序

✗ 3250 的 2 在十位

从右往左个十百千，2 在百位。

丢 0

✗ 3005 写成 35

中间百位十位是 0，要写 0 占位，是 3005。

读零

✗ 7010 读七千一十

百位是 0 要读零：七千零一十。

比大小

✗ 999＞1000

1000 是四位数，比三位数 999 大。

记住：数位从右往左、空位写 0、比大小从高位。

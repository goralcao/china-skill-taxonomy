起意 · 8 张「假如」卡，先撒开再收 1 张

「假如我会飞」「假如猫会说话」都能编。真正让读者读不下去的，不是想得太野，是前面说不会飞、后面直接飞上了天。

花 10 分钟把 8 张「假如」卡翻一遍：先随便点进素材池，再收 1 张进主格当故事起点。点哪张都行，不判好坏——空输入框等于把构思难题原样退回给你。

最后点 3 个「我还要写的词」。这一步只留一个痕迹：这个故事从哪儿起。

搭骨架 · 起因、经过、结果，三格各有任务

给三格排顺序：起因 → 经过（详）→ 结果（略）。每格填一句「这段要让人知道___」，再点详略。

这里只报「三格功能填了几格、详略点了几格」，不判好坏，填不完整也能往下走。

  • 起因给故事一个头，经过写最要紧的那一步，结果一句收住，别跳脱。
  • 每格填一句功能，让三段各有任务；别让起因跑到经过后面去。
  • 详的那段多写几行，略的一段带过；详略点一下就行，不用写理由。
↑ 上移起因：故事从哪儿起、主角是谁详略
↑ 上移经过：最要紧的那一步发生了什么详略
↑ 上移结果：后来怎么样了详略
每格都填一句「这段要让人知道___」，再点一下详略。三格可以上移调顺序，别让起因跑到经过后面去。
三格功能 0 / 3 · 详略 0 / 3（不判好坏，填不完整也能往下走）

起草 · 先定格式，三格把故事写完整

「故事名字」「主角」做成填空条前置锁定；三格各顶一句「这格写什么」，写多写少都行。

这里只判写没写，不判好坏。先写后看范文——这一页没有范文，也没有好词好句库。

格式条

名字 + 主角

先定下来。

三格

起 / 经 / 结

各写各的。

存本

写没写看得出

好坏不打分。

先填故事名字和主角，把格式定下来；没填也照样能写（不拦路）。
第一格 · 开头：故事从哪儿起
第二格 · 中间：最要紧的那一步（详）
第三格 · 结尾：后来怎么样了（略）
三格写了 0 / 3 行（只判写没写，不判好坏）。这里没有范文。

改 · 按矛盾检查，把接不上的地方补回句子

先点右边一条矛盾，草稿高亮可疑句；再点左边一句，才算记下一处改动。增删改调换，不给分数。

已改 0 / 5 处（改的是句子，不是错别字） 先自己试一次，再看老师改这一句

红删、绿增、蓝调；「想得够不够大胆」不打分，只查前后接不接得上

  • 点清单只算看到问题，点中句子才算改过；改完左右对照。
  • 能给学生看的只有事实：前面说不会飞、后面直接飞了。
  • 不判情感、不判立意、不给想象打分；只补一句把设定接上。

出刊 · 我的一页故事

把三格拼成一页，署上自己的名字，对着三条标准自查，再点「发布」。勾不满也能出刊。

顺手把四个易错点看一遍：别把前后矛盾留着，别让经过一句跳过，别先发范文再说照着写，也别给「想得够不够大胆」打分。

① 一个头

全篇只起一个头

不打架。

② 不跳脱

经过写清那一步

接得上。

③ 能连起来

读一遍给别人

不打分。

（还没起草。回到「起草」那一页写三格，它就会出现在这页书上。）
① 全篇只起一个头，没有第二个「假如」 ② 经过写清了最要紧的那一步 ③ 读一遍，起因经过结果能连起来
三条只问「这一段接得上吗」，不问「想得野不野」——勾不满也照样能出刊。

这一页没有分数，也没有排行榜。机器能说的是「事实」：前面说过什么、后面接没接上；「故事好不好」由你自己读一遍说了算。

这一课，装进四张卡

1
留下的是一页故事，不是分数
起意 → 出刊
▼

写作课的产出物是一页能读的东西：全文＋署名。

过关的实质是写前想清楚、写后知道补哪一句。

2
大胆又合理
8 张卡 → 1 个起点
▼

想象不作限制；合理指的是前后不自己打自己。

一个故事只起一个头，别把八张「假如」全编进去。

3
最容易翻车的三处
矛盾 / 跳脱 / 好词库
▼

前面说不会飞、后面直接飞了，是矛盾检查专抓的一处。

经过只一句就跳到结尾；输入框旁挂好词库教的是拼贴。

4
只给事实，不给判断
增 删 调 换
▼

能给学生看的是「这两句接不上」，不能给的是大胆程度评分。

一条 0.8 元，25 条扣了 20 元

短信一条 0.8 元，这个月发了 25 条。账单一共扣 20 元。

可 8 × 25 = 200，怎么少了整整十倍？差的那十倍，就藏在小数点上。

0.8 不是 8，是 8 个 0.1。8 个 0.1 乘 25，得到 200 个 0.1，也就是 20。

整数那步没变

8 × 25 = 200

这一步四年级就熟了，照旧算。

0.8 是 8 个 0.1

0.8 = 8 × 0.1

乘出来的 200，单位是 0.1，不是 1。

200 个 0.1

200 × 0.1 = 20

小数点往左挪一位，20 元就对上了。

小数乘法不是新算法，是整数乘法加一道「小数点归位」。归几位，由两个因数的小数位数决定。

先当成整数乘，再数小数位数

把 0.8 看成 8，25 不变，先算 8 × 25 = 200。

0.8 有 1 位小数，25 有 0 位，合起来 1 位。从 200 的右边起数 1 位点上小数点：20.0，就是 20。

  • 第一步：两个因数都当整数，按整数乘法算
  • 第二步：数一数两个因数一共几位小数
  • 第三步：从积的右边起，数出同样多位，点上小数点
积的小数位数 = 两个因数小数位数之和。不是取多的那个，也不是都按一位算。

这些算式，积各是多少

都走同一条路：先整数乘，再看一共几位小数。算出来再连线。

位数不够补 0，末尾的 0 可以划掉

0.25 × 8：25 × 8 = 200，两位小数，从右边数两位 → 2.00。末尾两个 0 不写，就是 2。

0.2 × 0.3：2 × 3 = 6，可要两位小数，6 只占一位，前面补一个 0 → 0.06。

末尾去 0

2.00 → 2

小数末尾的 0 不影响大小，写不写都对，习惯上划掉。

位数不足补 0

6 → 0.06

小数点后左边不够位，要补 0 占位，少一个就错十倍。

补在点后

0.5 × 0.2 = 0.10 = 0.1

5 × 2 = 10，两位小数 → 0.10，末尾 0 划掉。

补 0 和划 0 都只占位，不改变大小。区别是：补在小数点后左边，划在最末尾。

把小数点拖回家

中间这串数字是「当整数乘」算出来的积，红点还停在最右边。按「左移一位」把它挪回去，也可以直接点两个数字之间的缝。挪对位置，读数才等于真正的积。

四个坑，掉进去就错十倍

坑一：像加法一样对齐

0.8 × 25 小数点对齐 ✗

对齐是加法、减法的规矩。乘法先把小数点扔一边，算完再数位数。

坑二：位数取多的那个

0.8 × 0.5 点 1 位得 4 ✗

8 × 5 = 40，两位小数 → 0.40 = 0.4。取一位就放大十倍。

坑三：忘了补 0

0.2 × 0.3 = 6 ✗

两位小数得写成 0.06。少补一个 0，答案就差十倍。

坑四：不算就交卷

0.8 × 25 = 200 ✗

0.8 元不到 1 元，25 条不会超过 25 元。200 一眼就该被拦下来。

算完做两件事：数位数管小数点在哪，估大小管结果离不离谱。两关都过才算完。

回到话费单：0.8 一位、25 零位，8 × 25 = 200 点一位 → 20.0 = 20 元。估一下：25 条每条不到 1 元，20 元合理 ✓

这一课，装进四张卡

1
是什么
先按整数乘，再点小数点
▼

小数乘法 = 整数乘法 + 小数点归位。两个因数的小数点先不管，算完再安回去。

0.8 × 25 就是 8 × 25 = 200，再点一位得 20。

2
为什么
0.8 是 8 个 0.1
▼

0.8 不是 8，是 8 个 0.1。乘出来 200，单位是 0.1，所以是 20。

位数相加的道理也在这：一位小数乘一位小数，得到的是「百分之一」为单位，所以两位。

3
怎么用
三步，一步都不能省
▼

① 两个因数都当整数，乘出积。

② 数两个因数一共几位小数。

③ 从积的右边起数出同样多位，点上小数点；位数不够前面补 0，末尾多余的 0 划掉。

4
易错
不对齐、不补 0、不估算
▼

坑一：像加法一样把小数点对齐。

坑二：位数取多的那一个。

坑三：0.2 × 0.3 写成 6，忘了补 0。

坑四：0.8 × 25 算出 200 就交卷，没估大小。

记住这一句：小数乘法 = 整数乘法 + 小数点归位；位数是加出来的，不是猜出来的。

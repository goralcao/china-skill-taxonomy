有 3 个球，再添上 2 个，用加法：3+2=5。

有 5 个球，拿走 2 个，用减法：5−2=3。

加减是一对（互逆）

3+2=5，那么 5−2 就一定等于 3。

一道加法能写出两道减法，用数的组成来想。

  • 看到 a + b = c，就有 c − b = a。
  • 用数的组成：5 分成 3 和 2，所以 5−2=3。
  • 加 0、减 0 都还是原数。
加减互逆：会用加法，就会用减法检查。

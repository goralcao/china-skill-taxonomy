45 人、1200 人、80 万人，同一件事换了三个量级，读法为什么不一样？

45 人，一眼能数清；1200 人，还读得出来；到了 800000，六个数字摆在那儿，先数几个 0 就够费劲。一个人张开手臂大约 1 米 20 厘米，45 人排开 54 米，一个操场装得下；80 万人排开，要排到 960 公里外。

问题不在数字多，在于没看清每个数字站在哪一位。同一个「8」，站在个位是 8，站在十万位就是 80 万。

所以大数不是靠一个个数，是靠认位：先认出它在哪一级，再读那一位上的数。

一个数字的值 = 它本身 × 它所在位表示的计数单位。8 在十万位，就是 8 个十万。

① 班级 → 学校

1200 ÷ 45 ≈ 27 倍

一所学校的人数，抵得上二十七个班。

② 学校 → 县城

800000 ÷ 1200 ≈ 667 倍

一个县的人数，抵得上六百多所学校。

③ 位数也在长

2 位 → 4 位 → 6 位

每多两位就是一百倍。先看位数，比先数 0 快得多。

从右边起第五位，为什么叫万位？

因为每往左一位，单位就乘 10：个、十、百、千，第五位正好是万。再往左是十万、百万、千万，第九位是亿。

  • ① 计数单位：个、十、百、千、万、十万、百万、千万、亿……
  • ② 数位：计数单位所占的位置。第五位叫万位，第九位叫亿位。
  • ③ 进率：10 个一万是十万，10 个十万是一百万，10 个一千万是一亿。
记住一句话：位是位置，单位是这一位值多少。8 在万位，就是 8 个万。

800000 有五个 0，怎么一眼看出它是 80 万？

办法是从右往左，每四位画一条分级线。线一画，数就分成几段，每段叫一级：个级、万级、亿级。

① 先分级

从右往左
每四位一条线

分完级，每一级最多四位，再也不会数错 0。

② 再读级

每级按个级读
读完加「万」或「亿」

万级读完加「万」，亿级读完加「亿」，个级不加。

③ 零怎么读

级末尾的 0 不读
中间连着几个 0 只读一个

「80 0000」读八十万，后面四个 0 一个也不读。

改写只是换单位，不改大小：800000 = 80 万，1200000000 = 12 亿。

数位表拨珠：每一位动一次，读法跟着变

每个数位上方点「＋」加 1、「－」减 1（0 到 9 循环）。右边实时给出读法——注意 0 什么时候读、什么时候不读。

读作：八十万 级末尾的 0 不读，中间连着几个 0 只读一个

三组色块就是三级；每级四位，读完加「万」或「亿」

四种错法，都错在零和级

① 少写一个 0

✗ 八十万 = 80000

80000 是八万。八十万要在万级写 80，后面再接四个 0：800000。

② 级名漏读

✗ 1200000000 读十二

亿级的数读完要加「亿」：十二亿。不加级名，数就缩了一亿倍。

③ 零全读出来

✗ 800000 读八十零零零零

级末尾的 0 一个也不读。中间连着几个 0，也只读一个「零」。

④ 改写当成四舍五入

✗ 1234567 ≈ 123 万

改写只换单位、不改大小，只能对整万整亿的数做。1234567 不能直接写成 123 万。

四种错法一个根子：没先分级，也没想清楚每个 0 站在哪一级。

回到封面那道题：一个县 80 万人，写作 800000；如果是 80 万零 45 人，就写成 800045，读作八十万零四十五。

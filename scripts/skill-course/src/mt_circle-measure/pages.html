直径 10 厘米的圆，滚一周走了多远

把一个直径 10 厘米的圆片沿直尺滚一圈，停下时读数约是 31.4 厘米。滚过的这段就是周长，它差不多是直径的 3 倍多一点。

换大小不同的圆再量，周长 ÷ 直径 总是同一个数，约 3.14，这个固定的倍数叫圆周率 π。

于是 C = πd = 2πr。计算时 π 通常取 3.14；π 是无限不循环小数，3.14 只是近似值。

测量

滚一周

走过的长度 = 周长。

规律

C ÷ d ≈ 3.14

与圆大小无关。

公式

C = πd = 2πr

知直径或半径都能算。

π 不是某一步算出来的，而是量出来的固定倍数：任何圆的周长都是它直径的 π 倍。

把圆切成小份拼成长方形，面积 = πr²

把圆平均切成 16 份、32 份……越切越细，交错拼起来就越接近一个长方形：长是周长的一半 πr，宽是半径 r。

所以 S = 长 × 宽 = πr × r = πr²。半径 10 厘米时，C = 62.8 厘米，S = 3.14 × 10² = 314 平方厘米。

  • 切得越细，拼出的图形越接近长方形
  • 长 ≈ 半周长 = πr，宽 = r
  • S = πr²
  • 已知直径先求半径：r = d ÷ 2
面积公式不是死记的：把圆「化曲为直」拼成长方形，长 πr、宽 r，一乘就得 πr²。

公式与它的来处，连一连

左边是量或公式，右边是它的含义。把相配的连起来。

栅栏是周长，草皮是面积

绕花坛一圈的栅栏、沿跑道跑一圈，求的是周长，用长度单位（米、厘米）；铺满草皮、刷漆，求的是面积，用平方单位（平方米、平方厘米）。

特别小心半圆的周长：它不是整圆周长的一半，还要加上那条直径，即 πr + 2r。

周长

C = πd = 2πr

单位：米、厘米。

面积

S = πr²

单位：平方米、平方厘米。

半圆周长

πr + 2r

半圆弧 + 直径，别漏。

半径扩大 2 倍时，周长只扩大 2 倍，面积却扩大 4 倍（2²）——因为面积里半径是平方。

滚动量周长，切拼逼近面积

换一个半径，按「滚一圈 → 切成小份 → 拼成长方形 → 读出 C 与 S」一步步看，切得越细拼得越像长方形。

第 1 组 · 半径 3 厘米 · 还没滚 点画布或按钮推进

切得越细，拼出的图形越接近长方形：长 πr、宽 r

  • 滚一圈走过的长度就是周长 C = 2πr。
  • 长方形长 ≈ 半周长 πr，宽 = r。
  • S = πr × r = πr²；周长用长度单位，面积用平方单位。

四个易错点，都在「平方」和「单位」上

圆的周长面积最容易错的地方，是把 r² 算成 2r，以及把周长和面积的单位写混。

坑一：r² 当成 2r

r = 3 时 πr² 算成 3.14×6 ✗

r² = 3×3 = 9，应是 3.14×9 = 28.26。

坑二：单位写错

面积写成 12.56 厘米 ✗

面积要用平方厘米、平方米。

坑三：半圆周长漏直径

半圆周长 = πr ✗

还要加一条直径：πr + 2r。

坑四：直径直接代入 r

d = 10 就算 π×10² ✗

先求 r = 5，再算 π×5²。

一句话：周长 C = πd = 2πr（长度单位），面积 S = πr²（平方单位）；r² 是 r 乘 r，不是 2 乘 r。

回到开头那个花坛：假设半径 5 米，栅栏要 C = 2 × 3.14 × 5 = 31.4 米，草皮要 S = 3.14 × 25 = 78.5 平方米。若错把 5² 当成 10，草皮就少算了一半。

面包 3.5 元、牛奶 2.8 元，一共要付多少元？

两个价签都是 3 元多、2 元多。先把角那一位加起来：5 角 + 8 角 = 13 角。

13 角超过 10 角，就换成 1 元 3 角。整数部分 3 + 2 再加进上来的 1，得 6 元。

合起来 6 元 3 角，就是 6.3 元。整个过程没用到新算法，只是把角当单位数了一遍。

一位小数加减的核心：角跟角加、元跟元加——换成分数条说，就是 0.1 跟 0.1 加。

0.3 + 0.4

3 个 0.1 + 4 个 0.1
= 7 个 0.1
= 0.7

不满十，直接数完写下来。

0.7 + 0.6

7 个 0.1 + 6 个 0.1
= 13 个 0.1
= 1.3

满十进一：13 个 0.1 就是 1 元 3 角。

1.2 − 0.5

12 个 0.1 − 5 个 0.1
= 7 个 0.1
= 0.7

不够减就先拆：1.2 就是 12 个 0.1。

把每个数换成「几个 0.1」，加减就变成整数题

0.3 是 3 个 0.1，0.4 是 4 个 0.1。加起来 7 个 0.1，写回小数就是 0.7。

换成「几个 0.1」以后，加的就是 3 + 4 = 7，跟整数加法一模一样。

  • ① 换：0.3 → 3 个 0.1；1.2 → 12 个 0.1（整数部分每个算 10 个）。
  • ② 算：像整数一样加或减，得到「几个 0.1」。
  • ③ 换回：满十进一，13 个 0.1 = 1.3；不满十就写 0.几。
竖式里为什么要小数点对齐？因为对齐了，0.1 才跟 0.1 站在同一列。

回到封面那道题：0.3 是 3 个 0.1，0.25 是 2 个 0.1 加 5 个 0.01。0.01 比 0.1 小一位，不能和 0.1 直接相加——得先把 0.3 写成 0.30，让两个数的位对齐。

一句话：加的是同一种单位。0.1 只能跟 0.1 加，0.01 只能跟 0.01 加。

满十进一、退一当十——小数也守这两条规矩

十格条只有 10 格，第 11 个 0.1 就装不下了，得换成整 1。

① 满十进一

0.7 + 0.6
= 7 + 6 = 13 个 0.1
= 1.3

13 个 0.1 就是 1 个整再加 3 个 0.1。

② 退一当十

1.2 = 12 个 0.1
12 − 5 = 7 个 0.1
= 0.7

2 减 5 不够，就把整 1 拆成 10 个 0.1 一起减。

③ 小数点不能丢

0.6 + 0.3 = 0.9
不是 9
也不是 0.09

算的是「几个 0.1」，答案还得写回小数。

两条规矩合成一句：换成几个 0.1 再算，算完别忘了换回小数。

四种错法，都错在「对齐」和「换回」

① 末位对齐

✗ 0.3 的 3 对着 0.25 的 5

要对齐的是小数点：十分位对十分位，缺的位补 0。

② 算完丢了小数点

✗ 0.7 + 0.6 = 13

13 个 0.1 是 1.3，答案必须写回小数。

③ 反着减

✗ 1.2 − 0.5 = 0.3

2 减 5 不够，退一当十：12 − 5 = 7，得 0.7。

④ 结果乱添 0

✗ 0.3 + 0.4 = 0.70

一位小数加一位小数，结果还是一位：0.7。

四种错法根子相同：没把「几个 0.1」和「小数写法」来回换清楚。

回到小票：3.5 + 2.8 = 6.3 元。5 角加 8 角是 13 角，进 1 元剩 3 角——进位就发生在这一位。

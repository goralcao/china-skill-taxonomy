起意 · 8 张感官卡，先撒开再收 1 张

同一个橘子，有人只写「很好吃」，有人写出「皮上坑坑洼洼，剥开时一股清香窜出来」。差别不在词多，在用了几个感官。

花 10 分钟把 8 张感官卡翻一遍：先随便点进素材池，再收 1 张进主格当观察对象。点哪张都行，不判好坏——空输入框等于把构思难题原样退回给你。

最后点 3 个「我还要写的词」。这一步只留一个痕迹：我打算从哪几处写。

搭骨架 · 三格各管一处，顺序轴不许乱

给三格排顺序：从外到内，或者连着三天。每格填一句「这部分要让人知道___」，再点一下详还是略。

这里只报「三格功能填了几格、详略点了几格」，不判好坏，填不完整也能往下走。

  • 顺序轴只有两条：从外到内（先看皮、再看瓤），或连着三天（第一天→第三天）。
  • 每格填一句功能，让三段各有任务；别把看、听、闻、摸全挤进同一格。
  • 详的那段多写几行，略的一段带过；详略点一下就行，不用写理由。
↑ 上移从外到内：先写皮上看到什么详略
↑ 上移连着三天：每天各变成什么样详略
↑ 上移我的发现：和第一天不一样的地方详略
每格都填一句「这部分要让人知道___」，再点一下详略。顺序轴可以上移调先后，别把看、听、闻、摸搅在一格里。
三格功能 0 / 3 · 详略 0 / 3（不判好坏，填不完整也能往下走）

连一连 · 四条感官和四条规矩，各回各家

左边是观察时的做法，右边是它管的事。连完不用交卷，只看自己能不能说清「为什么」。

起草 · 先定格式，三格各写一处感官

「观察对象」「第几天」做成填空条前置锁定；三格各顶一句「这格写什么」，写多写少都行。

这里只判写没写，不判好坏。先写后看参考稿——这一页没有范文，也没有好词好句库。

格式条

对象 + 第几天

先定下来。

三格

看 / 听摸 / 变化

各写各的。

存本

写没写看得出

好坏不打分。

先填观察对象和第几天，把格式定下来；没填也照样能写（不拦路）。
第一格 · 我看到的（颜色、形状）
第二格 · 我听到 / 摸到 / 闻到的（详）
第三格 · 我发现的变化（略）
三格写了 0 / 3 行（只判写没写，不判好坏）。这里没有范文。

改 · 按体检单，改的是句子

先点右边一条体检项，全文高亮可疑句；再点左边一句，才算记下一处改动。增删改调换，不给分数。

已改 0 / 5 处（改的是句子，不是错别字） 先自己试一次，再看老师改这一句

红删、绿增、蓝调；错别字不在这张单子上，写得好不好也不打分

  • 点清单只算看到问题，点中句子才算改过；改完左右对照。
  • 能给学生看的只有事实：这个词出现 3 次、这段只用了眼看。
  • 不判情感、不判立意、不查好词好句；字数也只说「还差 X 字」。

出刊 · 我的一页观察记录

把三格拼成一页，署上自己的名字，对着三条标准自查，再点「发布」。勾不满也能出刊。

顺手把四个易错点看一遍：别把「很好看」当观察，别把看听闻摸搅在一格，别先发范文再说照着写，也别给「写得好不好」打分。

① 一个对象

全篇只写这一件

不跑题。

② 都相关

每句都是看见的

不掺水。

③ 看得见

读一遍给别人

不打分。

（还没起草。回到「起草」那一页写三格，它就会出现在这页书上。）
① 全篇只写一个观察对象 ② 每句都写的是我看见 / 听见的 ③ 读一遍，别人能看见我看见的东西
三条只问「这一段清楚吗」，不问「写得好不好」——勾不满也照样能出刊。

这一页没有分数，也没有排行榜。机器能说的是「事实」：三格写了几行、用了几种感官；「写得好不好」由你自己读一遍说了算。

这一课，装进四张卡

1
留下的是一页记录，不是分数
起意 → 出刊
▼

写作课的产出物是一页能读的东西：全文＋署名。

过关的实质是写前想清楚、写后知道改哪一处。

2
观察先撒后收
8 张卡 → 1 个对象
▼

空输入框等于把构思难题原样退回；先撒再收才想得出来。

四条感官：眼看、耳听、鼻闻、手摸，别只用一个「看」字。

3
最容易翻车的三处
空词 / 顺序乱 / 好词库
▼

「很好看」是判断不是观察；顺序轴一乱，变化就看不出来。

输入框旁挂好词好句库教的是拼贴；改错别字不等于「改」。

4
只给事实，不给判断
增 删 调 换
▼

能给学生看的是「这段只用了眼看」，不能给的是情感、立意评分。

点中一句才允许打勾；自评不合格也照样能出刊。

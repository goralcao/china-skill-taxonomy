起疑 · 兔子怎么会撞断脖子？

先读《守株待兔》。「兔走触株，折颈而死」——如果「走」是慢慢走，兔子怎么会把脖子撞断？这里就该停一下。

读到让你卡住的那一句，点它，让它变灰。点哪句都行，这里不判对错；灰的必须落在整句上。

取证 · 三样各补一块，场景才立得住

先选一条来源，再点一句原文把它划黄；下边写一句「我从注释／插图／经验知道……所以这里大概是……」。

三样对上不等于译得准。这里只报「已取证几处、场景写没写」，不逐字硬译，也不打分。

  • 注＝课文下的字词注释，图＝插图里画的动作，验＝自己已经知道的事，？＝三样还对不上。
  • 「走」是跑、「释」是放下、「耒」是农具、「冀」是希望、「身」是自己。
  • 场景和依据分开记：想法框非空、且至少一处指回第几句，才算留下痕迹。

说清 · 把注释接回场景

点左边一条注释，再点右边一句拼出来的场景，连成一组。用「我从注释知道……看图又……所以……」说清——不给分数，只看场景能不能落回原文。

注释与场景已对齐 0 / 3 组（不判对错） 先自己拼一次，再看老师连一条

左边是字词出处，右边是三样拼出的场景；场景说得粗一点也算一条真痕迹

  • 一条注释能撑住不止一处场景；对不上就换一篇重连。
  • 连线记「连没连」，依据另记「第几句」，两样分开留痕。
  • 把「走」讲成「行走」时，只提示「回注释、再看图」，不给分数。

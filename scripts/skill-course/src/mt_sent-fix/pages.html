读进去 · 一句话里，3 种毛病差在哪儿？

先给两句各 10 秒钟默读：「通过这次活动，使我明白了团结。」 和 「我们要不断改进学习成绩。」。

两句都读着别扭，但毛病不是一类：第一句少了主语，第二句动词和宾语配不上。点哪句都行，这里不判对错。

看出来 · 圈出该改的那一处

下面一排词里，有 3 处是这一句真正的毛病所在。点出来，点错也没关系。

这里只报「已圈出几处」，不标红、不拦路；圈够了才提示往下走。

  • 缺主语、同义叠用、动宾不配，各算一类，不要混成一团。
  • 点中一处就留一处痕迹，并看到它属哪一类。
  • 圈够 3 处，3 类毛病就都认全了。
通过使改进团结的重要
已圈出 0 / 3 处（点错不标红，也不拦你）
点一个词，看它是不是毛病落在的那一处。

写下来 · 给三行病句各改一处

三行，一行比一行隐蔽。改不出来就点支架块——但尽量自己先试。

这里只判「改没改」，不判好不好；改完记得回头读一遍，意思不能变。

第一行

缺主语

删一个词就够

第二行

重复

留一个估计

第三行

搭配

只换动词

卡住了就点一个，用不用随你：
这次活动使我明白了团结的重要。他十岁左右。我们要不断提高学习成绩。
三处都只动了一个词，原意一点没变。先写后看，才不会全班改成同一句。

改一处 · 补上那一处，句子立刻读顺

点下面的词块，把它补进句子里。每补一处，句子就变一次——这里不打分，只看有没有读顺。

已添 0 / 3 处（不判对错） 先自己改一次，再看老师改

骨架不动，只往上面动该动的那一处

  • 一条句子只坏在一处时，改动越少越稳。
  • 连线记「改没改」，依据另记「属哪类毛病」，两样分开留痕。
  • 改完必须回头读一遍，原意变了就算改错。

评一评 · 对着三条标准看自己改的那一句

怎么选都不影响往下走，也不给分数。这一页只输出「下一步该验哪一处」。

三条标准都只问「改动落得准不准、原意保没保住」，不问「句子漂不漂亮」。

顺手把这一课最容易翻车的地方再看一遍：别把「读着别扭」直接当病句，更别顺手把句子越改越长——改完意思变了，比没改还糟。

① 找得准

毛病归类

缺 / 重复 / 搭配

② 改得少

只动一处

不整句重写

③ 验得住

原意不变

改完再读

改动落点
合格：动了一处 良好：动在毛病上 优秀：只动那一处，别处没碰
归类清楚
合格：说得出别扭 良好：能归进 3 类 优秀：能说出为什么不是别类
原意守住
合格：句子读得通 良好：意思没变 优秀：比原句更顺，却还是同一句话
选一级，看看它要求什么。自评不合格也照样能翻页。

这一页只问「改动有没有落在毛病的那一处」，不问「句子写得好不好」。

这一课，装进四张卡

1
先归类，再动笔
缺 / 重复 / 搭配
▼

读着别扭不等于病句，先按 3 类逐一排查。

归类清楚了，改动往往只落在那一处。

2
改动越少越好
能删不添，能换不扩
▼

整句重写最容易悄悄换掉原意。

删一个词、换一个动词，通常就够了。

3
原意是底线
改完再读一遍
▼

「防止不再」这类否定重复，改错方向意思会反。

改完读一遍，确认还是原来那句话。

4
认出「没问题」也是本事
不是每句都要改
▼

「响起热烈的掌声」成分齐全、搭配得当，不必硬改。

这一课练的是判断，不是把句子改长。

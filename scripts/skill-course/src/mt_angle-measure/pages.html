两个角摆一起，为什么眼睛常看错？

两条边画得长一点，角看起来就「大」——这是错觉。把两条边各延长 3 厘米再比，张开的程度一点没变。角的大小只看两条边张开的程度，跟边画多长没关系。

要说出「多大」，得有个统一的单位。把半圆平均分成 180 份，每份就是 1 度，记作 1°。

量角器就是这么来的：一个刻了 180 份的半圆。可它有两圈刻度，读错一圈就差了整整一倍。

角的大小 = 两条边张开的程度，用「度」计量。边画多长都不影响。

① 生活里的直角

书角、窗框、地砖缝
都是 90°

直角是最容易认的角，拿它当尺子比一比。

② 比直角小

剪刀半开
约 30°～60°

张得比直角窄，都叫锐角。

③ 比直角大

门开到一半
约 100°～120°

比直角宽、又没摊平，都叫钝角。

量角器上有两圈数，0 到 180 和 180 到 0

外圈从右边 0 数到左边 180，内圈从左边 0 数到右边 180。同一根刻度线上，两圈的读数加起来正好是 180。

  • ① 中心：量角器底边正中的小点，量角时对准角的顶点。
  • ② 零刻度线：底边上标 0 的那条线，对准角的一条边。
  • ③ 两圈刻度：零刻度线在哪边，就读哪一圈——这条规则能避开九成的错。
零在右边读外圈，零在左边读内圈。读错圈时，度数正好变成 180 减去正确度数。

量角三步，第三步最容易读错

中心对顶点 → 零刻度线对一条边 → 看另一条边落在哪。三步里前两步是「放对」，第三步才是「读数」。

① 第一步：对中心

中心 → 顶点

差一毫米，读数就差好几度。这一步不能将就。

② 第二步：对零线

零刻度线 → 一条边

边压在 0 上，读出来的才是真度数。

③ 第三步：读那圈

零在右读外圈
零在左读内圈

读错圈，60° 会被读成 120°。

分类只看度数：小于 90 锐角、等于 90 直角、90 到 180 钝角、等于 180 平角、等于 360 周角。

转一转量角器：同一个角，两圈读出两个数

调角度，看两条边张开多少度。外圈和内圈会同时显示两个读数——只有对着零刻度线的那一圈才是真答案。

60° · 锐角 零在右边，读外圈 60°；内圈那个 120° 是错的

蓝色外圈从右往左读，橙色内圈从左往右读；两条边张开多少，角就是多少度

  • 把角调到 90°，内外圈读数还会不一样吗？为什么？
  • 调到 30° 时，内圈显示多少？两个数加起来是多少？
  • 调到 180°，两条边变成什么样子？
  • 为什么读数一定要看「零刻度线所在的那一圈」？

A大

四种错法，三种都出在「放」上

① 内外圈读反

✗ 60° 读成 120°

零刻度线在右边，就该读外圈。读内圈得到的是 180 − 60 = 120。

② 中心没对顶点

✗ 中心放在边的中间

中心一偏，两条边在刻度上的落点全变，读数整体偏大或偏小。

③ 边没压零线

✗ 边停在 10° 上就开始读

要先让一条边压在 0 上，读出的才是这个角的度数；从 10 读起，得减掉 10。

④ 以为边越长角越大

✗ 边画长了，角就大

角只看张开程度。把两条边延长，度数一点不变。

四种错法一个对策：先把中心、零线放准，再盯着零线那一圈读数。

回到剪刀那道题：两把剪刀张开的角如果都是 45°，不管刀刃多长，角度都一样大——只是边看起来长短不同。

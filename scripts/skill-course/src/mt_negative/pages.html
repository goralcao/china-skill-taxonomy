收入 200 元和支出 200 元，怎么区分

生活中有一对一对意义相反的量：零上和零下、收入和支出、上升和下降。只写「5 度」「200 元」分不清方向。

于是约定：把一种方向记作正（+，可省略），相反方向记作负（−，不能省）。零上 5 度是 +5℃，零下 5 度是 −5℃。

0 是分界：它既不是正数也不是负数。200 元收入写 +200 元，200 元支出写 −200 元，一眼看出方向。

正数

+5、+200

比 0 多，可省 + 号。

负数

−5、−200

比 0 少，必须带 − 号。

0

分界

不正也不负。

负数的价值在于给方向编了个号：先定「以谁为 0」，再定「哪边为正」，相反方向自然就是负。

数轴上 −5 在 0 左边，为什么 −2 反而更大

画一条数轴：0 是原点，向右为正、向左为负，每一格代表 1。数轴上越往右数越大，所以 −2 在 −5 右边，−2 > −5。

总的大小顺序是 正数 > 0 > 负数。负数离 0 越远（格数越多），数值反而越小。

  • 数轴三要素：原点 0、正方向、单位长度
  • 向右为正、向左为负
  • 越往右数越大：−2 > −5
  • 正数 > 0 > 负数
比较负数时别只看数字大小：先想它在数轴上站哪儿。−8 比 −3 更靠左，所以 −8 < −3。

四个易错点，都在「0」和「负号」上

学负数最容易错的地方，是把 0 当成正数或负数，以及以为数字越大负数就越大。

坑一：0 算正数

0 是正数 ✗

0 是分界，不正也不负。

坑二：漏负号

零下 5 度写成 5℃ ✗

必须写 −5℃，否则意思反了。

坑三：按数字比大小

−8 > −3 因为 8 > 3 ✗

数轴上 −8 更靠左，−8 < −3。

坑四：方向搞反

向左走数变大 ✗

数轴向右为正，越往右数越大。

一句话：先定 0 和正方向；负号不能省；0 不正不负；比较大小就到数轴上看谁更靠右。

回到开头的温度：零下 5℃ 是 −5℃，零上 5℃ 是 +5℃，两者相差 10℃。若把 −5 写成 5，就变成和零上 5℃ 一样，温差算成 0，全错了。

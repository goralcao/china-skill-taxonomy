208 × 4，错的人大多错在中间这一位

算 208 × 4，竖式只有三行。可中间的那个 0，最容易出事。

有人算出 802（十位忘了加进位），有人算出 232（把 0 那一步整个跳过了）。正解是 832。

就像一箱水 24 元，买 3 箱该付多少？有人写 27 元（24+3）——把「3 箱」当成了「多 3 元」。乘和加，第一步就得分清。

这一课练的，就是一位一位乘、进位接住、0 不漏。先看清顺序，再谈速度。

竖式：从个位起，一位一位乘

竖式不是摆设，它是你的草稿纸。规则只有三条。

  • ① 从个位算起：右边先算，因为进位是往左边送的。
  • ② 一位一位乘：用乘数依次去乘每一位，乘到哪一位，积就写哪一位下面。
  • ③ 满几十进几：某一位乘出来满 10，就向它左边一位进几（写个小数字记着）。
步骤算什么怎么写
个位3 × 4 = 12写 2，向十位进 1
十位2 × 4 = 8，加进位 1写 9
结果—92
顺序错了，进位就接不上。永远从个位起，这是竖式的铁律。

两种最容易错的 0：中间 0 和末尾 0

顺序对了，还可能在「0」上栽跟头。两种 0，两种解法。

① 中间有 0：也要乘，再加进位

208 × 4
个位 8×4=32 写2进3
十位 0×4+3=3
百位 2×4=8 → 832

0 那一位不能跳过，乘完还要把进位的 3 加上去。

② 末尾有 0：先不算，再补回

2000 × 3
先算 2 × 3 = 6
末尾 3 个 0 原样补回
→ 6000

末尾的 0 不参与乘法，但要一个不落地补回去。

③ 竖式 = 被压缩的口算

208 = 200 + 8
200×4=800，8×4=32
800+32 = 832

想不清某一步，就把数拆开口算一遍，和竖式对一对。

中间 0 要乘要加，末尾 0 先放着最后补——两个 0 完全是两码事。

竖式步进器：一位一位点，看进位怎么接

点「下一步」，从个位开始逐位乘，进位的小数字会写在对应数位上方。算完整个积是几，一目了然。

四种错法，都错在「0 和进位」

① 中间 0 漏加进位

✗ 208 × 4 = 802

十位只写了 0×4=0，忘了加个位进上来的 3。正解 832。

② 末尾 0 数错个数

✗ 2000 × 3 = 60

只补了 1 个 0。末尾有 3 个 0，都得补回：6000。

③ 顺序反了，从百位起

✗ 先算 2×4，进位无处放

不按个位起，进位送不出去。永远从个位往左一位一位算。

④ 不算就估，方向反了

✗ 208×4 ≈ 1600

把 208 看大成了 400。正确估算 200×4=80，积应在 800 左右。

四种错法，根子是同一个：没把「逐位乘 + 进位 + 0」当成一条流水线。

回到运动会：每箱水 24 瓶，买 3 箱 → 24×3：4×3=12 写2进1，2×3+1=7 → 72 瓶。

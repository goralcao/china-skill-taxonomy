## 二、判分边界：12 页里装下阅读五段

`chinese-reading-writing.md` 要求「**只判有没有痕迹、依据在哪，不判好不好**」，
并且明确「**关键词命中 ≠ 理解**」「开放表达永不给否定结论」。调和方式是按判分边界分层：

| 层 | 内容 | 判不判分 | 落在哪几页 |
|---|---|---|---|
| 唯一答案的阅读方法知识 | 本课 14 道题，每题带错因解析 | **判分** | p1 / p4 / p7 / p9 |
| 半开放（有规则可查） | 8 组连一连 | 连线组件判对错，不计分 | p3b |
| 开放表达 | 起疑、取证、对齐、说清、换文 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

> 14 题全部设计成有唯一答案的方法知识题，不碰开放表达；答案分布收敛到
> `{0:5, 1:5, 2:4}`，避免学生靠「都选 B」蒙对。
> 对齐页特意让**右栏槽数少于句卡数、必有干扰句、必有「都不支撑」筐**，
> 破掉「一一对应排除法」——连线和依据还要**分别记录**。

## 四、本课变体：只回放不评分的节拍台

本课是这批里唯一**技能型**的阅读课：机器听不见学生出声，
所以从头到尾**只回放、不评分**。14 题全部是「标点怎么读 / 不丢字加字」这类
可查的朗读方法知识，绝不碰「读得好不好」。

仿真是唯一的 `CN.replay = true` 分支：Canvas 底部画**按标点分段的节拍条**，
拍与拍之间换色并留一道竖线加空隙，把「逗号停半拍」直接画出来；
点句子记一次回放，读数只报「回放 X 遍（只回放，不评分） · 已标 Y / 3 处」。
其余三课走通用的「左块 → 右块连线」依据链工作台，互不干扰。

## 五、Canvas 仿真：不判分，只留痕迹

仿真是「**节拍回放台**」（`CN.replay = true`，四课里唯一的变体分支）：点左边一句，Canvas 底部按标点把句子切成拍、逐拍换色，标点后画一道竖线并留空隙；再点右边一处读法给这句标停顿。只报「回放几遍、标了几处」，**绝不说读得好不好**。两个案例：

- **清晨（第一组）**：3 句可回放（清晨，小鸟在树上唱歌。 / 你今天去不去公园？ / 我先把作业本放好，再出去玩。）
- **放学（换文）**：3 句可回放（放学了，雨还在下。 / 你把伞带上了吗？ / 我们一起走吧！）

`simAdd / simDemo / simNextCase / simReset / simBind` 保持第四代结构测试契约；
`SIM.hits` 供 Canvas 点击命中；画布着色、连线 16 元素、V4 展开均纳入自动回归。
结算页从 `localStorage` 读回学生在「取证」页写下的那一句，链才算是学生自己的。

### 修过的问题

1. 节拍条初版是 13px 逐字格，画布缩放后不到 10px，几乎看不清；
   改为 17px 字、按标点分段换色，标点后画竖线并留 12px 空隙，
   「停半拍」变成看得见的形状。
2. 读数初版把「回放几遍」和「已标几处」拼成一大句，顶部状态行过挤；
   `CN.replayNote` 收短成「回放 X 遍（只回放，不评分）」。
3. 配图 SVG 在 205px 宽下字太小，装配器把 `#p2fig/#p3fig/#p5fig`
   提到 244px 并统一 `svg text{font-size:14px}`，四课一起受益。

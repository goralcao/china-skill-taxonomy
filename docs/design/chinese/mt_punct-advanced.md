## 二、判分边界：12 页里装下语文六段

`chinese-design.md` 明确写了「**不要套数学的情境 → 探究 → 例题 → 练习 → 小结**」，
语文的过关是「**留下痕迹**」。调和方式是按判分边界分层：

| 层 | 内容 | 判不判分 | 落在哪几页 |
|---|---|---|---|
| 唯一答案的语言知识 | 本课 14 道题，每题带错因解析 | **判分** | p1 / p4 / p7 / p9 |
| 半开放（有规则可查） | 8 组连一连 | 连线组件判对错，不计分 | p3b |
| 开放表达 | 读进去、看出来、写下来、改一处、评一评 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

> 14 题全部设计成有唯一答案的语言知识题，不碰开放表达；每题答案分布收敛到
> `{0:5, 1:5, 2:4}`，避免学生靠「都选 B」蒙对。

## 四、本课变体：不同案例自带不同槽数

本课把「六段」里的**看出来**做成「圈并列的词」，因为点句读的第一步不是记符号，
而是先分清隔开的是**词**还是**分句**。圈画只报「已圈出 X / 3 处」，圈错不标红。

仿真用 `seq` 描述句子结构，三个案例的槽数不同（3 / 4 / 3）：并列词语三处顿号、
作品名四处书名号（成对）、并列分句两处分号加句末句号。因此 `simSlotCount()` 按
**每个案例自身的 `slots.length`** 取，读数会从「0 / 3」自动变成「0 / 4」——
这不是 bug，是案例自带的形状。单字符符号的候选块设了 42px 最小宽度，避免看不清。

## 五、Canvas 仿真：不判分，只留痕迹

仿真是「积木台」：点候选词块补进 `seq` 描述的句子，读数只报
「已添 X / N 处（不判对错）」，不给分数。三个案例：

- **并列词语**：3 个槽（第 1 处 / 第 2 处 / 第 3 处）
- **作品名**：4 个槽（书名前面 / 书名后面 / 第二本前 / 第二本后）
- **并列分句**：3 个槽（第 1 处 / 第 2 处 / 句末）

`simAdd / simDemo / simNextCase / simReset / simBind` 保持第四代结构测试契约；
`SIM.hits` 供 Canvas 点击命中；画布着色、连线 16 元素、V4 展开均纳入自动回归。

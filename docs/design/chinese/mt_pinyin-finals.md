## 二、判分边界：12 页里装下语文六段

`chinese-design.md` 明确写了「**不要套数学的情境 → 探究 → 例题 → 练习 → 小结**」，
语文的过关是「**留下痕迹**」。调和方式是按判分边界分层：

| 层 | 内容 | 判不判分 | 落在哪几页 |
|---|---|---|---|
| 唯一答案的拼音知识 | 本课 14 道题，每题带错因解析 | **判分** | p1 / p4 / p7 / p9 |
| 半开放（有规则可查） | 8 组连一连 | 连线组件判对错，不计分 | p3b |
| 开放表达 | 听一听、看一看、摆一摆、拼一拼、查一查 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

> 14 题全部设计成有唯一答案的拼音知识题，不碰开放表达；每题答案分布收敛到
> `{0:5, 1:5, 2:4}`，避免学生靠「都选 B」蒙对。题干压到一年级能读的短句，
> 字号、色块、按钮按一年级放大（`run_py.py` 的 EXTRA_CSS 覆盖层）。

## 四、本课变体：四声台与调型曲线

本课是整条链的**起点**：图谱里唯一没有 hard 前置的一课（`preExpected=0`，评分器自动给满图谱分）。
把「听一听」做成四声对照，把「拼一拼」做成 `CN.mode='tone'` 四声台：左格韵母、中格按
**调型曲线**画出平/升/拐/降、右格显示查表得到的带调韵母（`CN.toneMap`）。

一年级的调号 `ˉ ˊ ˇ ˋ` 是组合字符，小字号下会糊成一个点，所以候选块一律显示中文名
「一声/二声/三声/四声」（`CN.toneLabels`），形状交给 Canvas 的曲线去表达。

## 五、Canvas 仿真：不判分，只留痕迹

仿真是「音节台」：点候选块补进 `CN.cases` 的槽里，读数只报
「已摆 X / N 处（不判对错）」，不给分数。`CN.mode = tone`，三个案例：

- **a 的四声**：2 个槽（选韵母 / 选声调）
- **i 的四声**：2 个槽（选韵母 / 选声调）
- **o 的四声**：2 个槽（选韵母 / 选声调）

`simAdd / simDemo / simNextCase / simReset / simBind` 保持第四代结构测试契约；
`SIM.hits` 供 Canvas 点击命中；画布着色、连线 16 元素、V4 展开均纳入自动回归。
四个 mode 共用的绘制函数：`simOptLabel()` 把组合调号换成中文名、
`simToned()` 查表生成带调韵母、`simCompose()` 只负责展示不负责判定。

### 修过的问题

1. 开场衔接只有 3/5：标题有具体问题但缺「可感知的量」，
   在「听一听」补「先给两个音节各 10 秒钟」后回到 5/5。
2. 调号 `ˉ ˊ ˇ ˋ` 是组合字符，Canvas 小字号下糊成一个点，
   候选块改显中文「一声/二声/三声/四声」，形状改由调型曲线表达。
3. Canvas 放大到 296px 后 p6 溢出到 874px；收到 288px 并压缩
   `.sim-page` 底部留白与 notes 行距，回落 852 单屏。
4. 正文里连排的 `ī í ǐ ì` 渲染发糊，改成「i 上标调要去掉头上那一点」的文字描述。

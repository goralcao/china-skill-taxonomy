## 二、判分边界：12 页里装下写作五段

`chinese-reading-writing.md` 要求「**能给学生看的只有事实，不能给的是判断**」，
并且明确「**构思不能只给一个输入框**」「**错别字不属于改**」「不按字数 / 好词好句打分，不先发范文」。
调和方式是按判分边界分层：

| 层 | 内容 | 判不判分 | 落在哪几页 |
|---|---|---|---|
| 唯一答案的习作方法知识 | 本课 14 道题，每题带错因解析 | **判分** | p1 / p4 / p7 / p9 |
| 半开放（有规则可查） | 8 组连一连 | 连线组件判对错，不计分 | p3b |
| 开放表达 | 起意、搭骨架、起草、改、出刊 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

> 14 题全部设计成有唯一答案的方法知识题，不碰开放表达；答案分布收敛到
> `{0:5, 1:5, 2:4}`，避免学生靠「都选 B」蒙对。
> 起意坚持「**先撒 8 张卡、再收 1 张进主格**」——空输入框等于把构思难题原样退回；
> 起草只判「写没写」，出刊的三条自查**勾不满也照样能翻页**，全程没有一处说「写得好不好」。

## 四、本课变体：没有「写」，全程旧文、难点是敢删

本课是这批里**唯一没有「写」**的：全程用旧文，难点是**敢删**。
五段里的「起草」换成「**读旧文**」——抄原句、写改后、说一句为什么改，
不写新作文。起意的 8 张卡全是旧文里重复啰嗦的句子，
只收 1 张「我最想删的一句」进主格。

搭骨架按「字词 → 句子 → 内容」三层逐层查，句子层标「详」。
红线写得最直白：**错别字不属于「改」**——
它改的是字不是句子，改一节课只改几个字，文章还是老样子。
互评只指到具体一句、给一条能动手的建议，不下结论、不排名次。

## 五、Canvas 仿真：不判分，只留痕迹

仿真是「**体检单工作台**」：左边三句草稿、右边 5 条体检项，两步点击才记一处改动，读数只报「已改 X / 5 处」，不给分数。两个案例：

- **放学的伞（旧文）**：3 句草稿 × 5 条体检项（删 / 换 / 增 / 调 / 换）
- **早上的猫（换文）**：3 句草稿 × 5 条体检项（删 / 换 / 增 / 调 / 换）

两步才算改过：**点右边一条体检项只算「看到问题」（对应段变黄高亮），
再点左边一句 / 一格才记下一处改动**。为了不判对错，点哪一句都允许打勾——
规范要的是「点中一句才允许打勾」，不是「点中正确那句」。
`simAdd / simDemo / simNextCase / simReset / simBind` 保持第四代结构测试契约；
`SIM.hits` 供 Canvas 点击命中；画布着色、连线 16 元素、V4 展开均纳入自动回归。
读数写「**已改 X / 5 处（改的是句子，不是错别字）**」，不是分数。

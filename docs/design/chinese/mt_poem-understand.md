## 二、判分边界：12 页里装下阅读五段

`chinese-reading-writing.md` 要求「**只判有没有痕迹、依据在哪，不判好不好**」，
并且明确「**关键词命中 ≠ 理解**」「开放表达永不给否定结论」。调和方式是按判分边界分层：

| 层 | 内容 | 判不判分 | 落在哪几页 |
|---|---|---|---|
| 唯一答案的阅读方法知识 | 本课 14 道题，每题带错因解析 | **判分** | p1 / p4 / p7 / p9 |
| 半开放（有规则可查） | 8 组连一连 | 连线组件判对错，不计分 | p3b |
| 开放表达 | 起疑、取证、对齐、说清、换文 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

> 14 题全部设计成有唯一答案的方法知识题，不碰开放表达；答案分布收敛到
> `{0:5, 1:5, 2:4}`，避免学生靠「都选 B」蒙对。
> 对齐页特意让**右栏槽数少于句卡数、必有干扰句、必有「都不支撑」筐**，
> 破掉「一一对应排除法」——连线和依据还要**分别记录**。

## 四、本课变体：注释 ↔ 诗句 ↔ 画面的三方对齐

本课是**单首诗精读**：注释只解开一个词，把它放回整句，才说得出写了什么景。
主文本用统编三上《山行》，五个注释（寒山 / 石径 / 坐 / 霜叶 / 红于）全部可查，
其中「**坐＝因为**」是全诗最容易翻车的一处，前后测各出现一次。

「对齐」把四张卡归进「注释 / 诗句 / 画面大意」三栏，干扰卡是
「诗人那天穿了一件红衣裳」——诗里根本没写。仿真的左右两列因此不是
「原文 ↔ 想法」，而是「**课本给的注释 ↔ 我用自己话说的景**」，
读数写「注释与画面已对齐 X / 3 组」，连底部状态条文案也跟着换掉。

## 五、Canvas 仿真：不判分，只留痕迹

仿真是「**依据链工作台**」：点左边一块、再点右边一块连成一环，读数只报「已连 X / 3 环（不判对错）」，不给分数。两个案例：

- **山行（杜牧）**：左 3 条 × 右 3 条
- **赠刘景文（换文）**：左 3 条 × 右 3 条

`simAdd / simDemo / simNextCase / simReset / simBind` 保持第四代结构测试契约；
`SIM.hits` 供 Canvas 点击命中；画布着色、连线 16 元素、V4 展开均纳入自动回归。
结算页从 `localStorage` 读回学生在「取证」页写下的那一句，链才算是学生自己的。

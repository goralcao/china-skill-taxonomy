# 语文样板课 01 · 扩句与把句子写具体（mt_sent-extend）

> 三年级语文 · 句子 · `chinese-2022:S2:BQ`
> 这是小学语文课件升级到第四代的**样板课**，先验收风格，再放量到其余 15 课。

## 一、为什么先做这一课

`data/topics.json` 里 `mt_sent-extend` 已有图谱位置：前置 `mt_sent-complete`（完整句与句子成分）、
`mt_word-accumulate`（词语的归类与积累），后续 `mt_sent-compress`（缩句）、
`mt_write-observe`（观察与写清楚）。老引擎里也已有同名课件（`content.json`，`renderer=sentBuild`），
但 `standards: []` 且流程骨架是数学的，正好用来验证「第四代外壳 + 语文内核」是否成立。

## 二、核心矛盾与解法：12 页里装下语文六段

`chinese-design.md` 明确写了「**不要套数学的情境 → 探究 → 例题 → 练习 → 小结**」，
语文的过关是「**留下痕迹**」，不是「选中正确答案」。第四代流水线却要求 12 页、
4 套测验 14 题、1 个 Canvas 仿真、V4 总结。两者的调和方式是**按判分边界分层**：

| 层 | 内容 | 判不判分 | 落在哪几页 |
|---|---|---|---|
| 唯一答案的语言知识 | 「的/地」用法、哪个词写地方、哪句算扩句、位置放哪 | **判分** + 每题错因解析 | p1 / p4 / p7 / p9，共 14 题 |
| 半开放（有规则可查） | 词块归类连一连 | 连线组件判对错，但不计分 | p3b |
| 开放表达 | 读进去、圈画、动笔、改一处、自评 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

> `chinese.md`：只有「唯一答案」的语言知识可以判对错；扩句、造句、加标点说理由一律不判分，
> 只给量规与参考稿。14 道题因此全部设计成有唯一答案的语言知识题，不碰开放表达。

## 三、刻意不做的事（对照 `chinese-design.md` 第四节）

1. 不做「拖词进空格」式扩句 —— 仿真是把词块插进句子并**看见句子变化**，不是拖拽填空。
2. 不做「X / Y 一次答对」—— 仿真读数写的是「已添 X / 3 处（不判对错）」。
3. 不按字数 / 形容词个数打分 —— 量规三维都不涉及字数。
4. 不做同伴互评 —— 替代路径是「读给同桌听 / 自己回听」。
5. 不做朗读打分 —— 本课不接语音识别，`p10` 明说「没有麦克风，这一课照样上得完」。

## 四、仿真设计：`sentBuild` 的 Canvas 版

`simCanvas` 是「句子积木台」：墨绿色词块是骨架（小鸟 / 飞），朱砂色是学生添进去的修饰语。
三个槽分别回答「什么样的」「在哪里」「怎样地」，每槽 3 个候选词，**选哪个都不判对错**，
插入后句子实时变长、右侧面板只更新「添了几处」和「这一处回答了哪个问题」。

三组句子可切换：小鸟飞 / 小猫叫 / 小草长。按钮为「换一组句子 / 重来 / 看老师改这一句」，
演示按钮沿用语文口径的措辞「**先自己试一次，再看不迟**」，而不是数学的「一步一步算」。

符合 `chinese.md` 的 EVAL 第一问：**有一个「操作在句子上逐步生效」的过程**——学生做一次，句子就变一次。

### 修过的问题

- 封面 SVG 未给固有宽度，`.cover-fig` 被 shrink-to-fit 算成 0 宽 → 补 `width/height` 属性 + `.cover-fig{width:min(760px,88%)}`。
- p5 初版内容高 1272px，「存进句子本」被导航遮挡 → 隐藏与量规重复的三张卡、压紧凑输入区间距、收窄右侧示意图；最终 852px 一屏，按钮落在 681–710。
- p3 / p8 同类超屏 → 同样处理。
- Canvas 缩放后字偏小 → 句子词块 17→19px、槽区 14→15/16px，放大后无重叠越界。
- 开场 `hook` 初评 3/5（缺可感知场景）→ 在 p2 加「先给两句各 10 秒钟，默读一遍再点」。

## 六、后续 15 课的批量方案

1. 按 `courses/` 里已有 `content.json` 的 16 课语文课件逐课重做为 7 分片，课标编号从
   `data/topics.json` 直接取（177 个语文主题全部有 `chinese-2022:*` 编号，不存在缺编号问题）。
2. 课型先分流：`chinese.md` 的三种形状
   - 语言知识（句子、标点）→ 六段，本样板课形状；
   - 阅读（圈画批注、预测推想、古诗注释）→ 五段「起疑 → 取证 → 对齐 → 说清 → 换文」；
   - 写作（观察、日记、想象、修改）→ 五段「起意 → 搭骨架 → 起草 → 改 → 出刊」。
3. 每种课型各先做 1 课样板验收，再批量生成；每课仍走
   `c1.py → build_course.py → sync_one.py → score-course.mjs → answer_check → test-course.js → shots.js`。
4. 新增语义回归：沿用数学的 `scripts/skill-course/semantic-check.py` 思路，
   对语文 14 题按「正确答案文本」断言，防止选项重排后 `answer` 索引错配。
5. 全部做完再统一执行 4B 发布、链接总表与教师必看页；样板阶段只做 4A 链路回归，不发布。

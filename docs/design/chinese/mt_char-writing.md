## 二、判分边界：12 页里装下写作五段

`chinese-reading-writing.md` 要求「**能给学生看的只有事实，不能给的是判断**」，
并且明确「**构思不能只给一个输入框**」「**错别字不属于改**」「不按字数 / 好词好句打分，不先发范文」。
调和方式是按判分边界分层：

| 层 | 内容 | 判不判分 | 落在哪几页 |
|---|---|---|---|
| 唯一答案的习作方法知识 | 本课 14 道题，每题带错因解析 | **判分** | p1 / p4 / p7 / p9 |
| 半开放（有规则可查） | 8 组连一连 | 连线组件判对错，不计分 | p3b |
| 开放表达 | 起意、搭骨架、起草、改、出刊 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

> 14 题全部设计成有唯一答案的方法知识题，不碰开放表达；答案分布收敛到
> `{0:5, 1:5, 2:4}`，避免学生靠「都选 B」蒙对。
> 起意坚持「**先撒 8 张卡、再收 1 张进主格**」——空输入框等于把构思难题原样退回；
> 起草只判「写没写」，出刊的三条自查**勾不满也照样能翻页**，全程没有一处说「写得好不好」。

## 四、本课变体：田字格描红，只对照不打分

本课是唯一**技能型**的写作变体：走 `writeChar`，**田字格描红，
只对照不打分**，也不做朗读打分。装配器为此开了两个专用分支：

- `draft.grid = true`：起草页从三条宽文本框换成**三个正方形田字格输入**
  （我 / 你 / 他，带横竖中线，单字输入）。
- `CN.charGrid = true`：Canvas 左栏从三句草稿换成**三个田字格**，
  右栏是 5 条书写规范；点一条、点一格，只报「已对照 X / 5 处」。

机器能给的只有事实：横贴没贴中线、有没有一笔出格、三个字是不是一般大；
「字写得好不好」属于判断，从头到尾不显示。三个「一」（一拳 / 一尺 / 一寸）
在前测、连一连、后测里各查一次，防止记混。

## 五、Canvas 仿真：不判分，只留痕迹

仿真是「**田字格对照台**」（`CN.charGrid = true`，五课里唯一的变体分支）：Canvas 左栏画三个正方形田字格（外框 + 横竖中线 + 大字 + 第几格），右栏是 5 条书写规范。点一条、点一格，只报「已对照 X / 5 处（只对照，不打分）」。两个案例：

- **我 / 你 / 他**：格子「我 / 你 / 他」，5 条规范（横中线 / 竖中线 / 摆正 / 大小一致 / 不出格）
- **口 / 日 / 田（换一组字）**：格子「口 / 日 / 田」，5 条规范（横中线 / 竖中线 / 摆正 / 大小一致 / 不出格）

两步才算改过：**点右边一条体检项只算「看到问题」（对应段变黄高亮），
再点左边一句 / 一格才记下一处改动**。为了不判对错，点哪一句都允许打勾——
规范要的是「点中一句才允许打勾」，不是「点中正确那句」。
`simAdd / simDemo / simNextCase / simReset / simBind` 保持第四代结构测试契约；
`SIM.hits` 供 Canvas 点击命中；画布着色、连线 16 元素、V4 展开均纳入自动回归。
读数写「**已改 X / 5 处（改的是句子，不是错别字）**」，不是分数。

### 修过的问题

1. 描红页初版沿用通用三行宽文本框，看不出田字格；装配器新增
   `draft.grid` 分支，改画三个正方形田字格输入（带横竖中线、单字输入），
   同时新增 `CN.charGrid` 分支，把 Canvas 左栏也换成三个田字格。
2. 中测二第 3 题原选项「出声读一遍自己写的字」放在写字课里别扭，
   容易被误认成「不允许做的事」；换成「把三个字和范字并排放着看」，
   三项里只有「给字打分」不属于允许范围，语义无歧义。

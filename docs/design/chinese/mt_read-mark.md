# 语文样板课 02 · 圈画与批注（mt_read-mark，阅读卷）

> 第四代交互式课件 · 小学语文 · 三年级 · 阅读方法课
> 设计依据：`skills/k12-courseware/references/chinese-reading-writing.md` 第二节（阅读五段）
> 同系列：`mt_sent-extend.md`（语言知识六段）、`mt_write-diary.md`（写作五段）

## 一、为什么先做这一课

`courses/` 里原有 16 课语文课件走老引擎，其中 9 课 `standards` 为空；第四代流水线
`scripts/skill-course/src/` 下 68 个源全是数学。第一份样板 `mt_sent-extend` 证明
**语言知识课六段**能同构进 12 页，但共识稿明确写着「六段也不够用」：

> 语言知识（句子/标点）产出「改对的一处」，六段；
> 阅读产出「一条依据链」，五段：起疑 → 取证 → 对齐 → 说清 → 换文；
> 写作产出「一页能读的东西」，五段：起意 → 搭骨架 → 起草 → 改 → 出刊。

`mt_read-mark` 是阅读方法课的起点（`renderer=annotate`），规范 2.3 专门定义了它的
痕迹是「符号系统 ○ □ ～ ？」，2.2 又给了防退化成配对游戏的四条硬规则。它最能验证
「依据链」这套骨架能不能在第四代外壳里落地。课标 `chinese-2022:S2:LR`，
前置 `mt_read-silent` / `mt_word-understand`，后续 `mt_read-predict` / `mt_read-question`。

## 二、核心矛盾与解法：12 页里装下阅读五段

数学第四代是「爬楼梯」，每一步收敛到一个答案；阅读是「来回跑」，产出物是
**一条能指回原文的依据链**。解法与语言知识课一样，按**判分边界分层**：

| 层 | 内容 | 判分 | 页面 |
|---|---|---|---|
| 唯一答案的阅读方法知识 | 四个符号、旁批规矩、依据定位、干扰句、防排除法 | **判分** + 每题错因解析 | p1 / p4 / p7 / p9，共 14 题 |
| 开放表达 | 起疑、取证、对齐、说清、换文 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

**p3b 为什么可以做成一一配对**：规范 2.2 反对的是「阅读理解判断」被压成左右一一对应
（学生靠排除法通关、一个字不读）。p3b 连的是**符号系统的约定**这类语言知识，
有唯一答案；真正的「对齐」放在 p5，按 2.2 做了四件事：右栏观点（2）少于句卡（4）、
必有 1 张干扰句、必有「都不支撑」筐、连线后强制补「我是根据第几句连的」。

## 三、刻意不做的事（对照共识稿）

三条共同红线（评价专家定）全部落实：

1. **只判「有没有痕迹、依据在哪」，不判「好不好」** —— p3 取证只报「已取证 X 处、
   想法写没写」；p5 对齐只报「已归位 X/4、依据补了 X/4」；把干扰卡放进观点槽也照收，
   只回执不标红。
2. **关键词命中 ≠ 理解** —— 页面明写「划中不等于读懂」，绝不说「你懂了」；
   后测第 10 题直接考这条。
3. **机器判错时学生改的是对的判断** —— 想法和原文对不上时只说「再读第 X 段」，
   不给分数、不说对错；「我猜错了」被当成最诚实的一环保留下来。

另外刻意不做：找中心句 / A B C D 选择题式的「假阅读」；朗读打分；同伴互评；
「X / Y 一次答对」式结算；排行榜。平台热门玩法只借了「大情境」，
不借判对错与闯关得分。

## 四、仿真设计：依据链工作台（Canvas）

`course.js` 里的 `simDraw()` 画一张双栏工作台：左栏 3 块原文句（标第几段），
右栏 3 块想法（含一条「我原先猜它饿了，后来发现猜错了」），中间连线。
点左句选中 → 点右想法连成一环，已连的线变橙实线，未连的画淡虚线。

- 读数写「**依据链已连 X / 3 环（不判对错）**」，不是分数。
- `simNextCase()` 换一组《雨里的一把伞》原文与想法，只用划和连，与 p8 换文呼应。
- `simDemo()` 的文案是「看老师连一条：先自己试一次，再看不迟」，第三环特意连到
  「我猜错了」，呼应规范 2.3 里预测策略课「至少 1 条敢写我猜错了」。
- 所有自编文本（约 138 字 3 段、每段 ≤ 60 字）都不取自教材，避开版权；
  古诗公有领域规矩同样适用。

### 修过的问题

1. p5 对齐：卡片归位后会被移进槽里，点卡内「第几段」按钮会**同时命中槽**，
   导致重复执行归位逻辑。改为依据按钮优先判断，并在归位后清空选中态。
2. p6 底部三条说明换行撑高到 871px；缩短文案后仍有 19px 来自
   `.sim-page` 底部 40px 固定留白，对 p6 单独收到 18px，全页回落 852px。
3. 封面 SVG 沿用样板课的 `width="760" height="190"` 固有宽度，避免 shrink-to-fit 算成 0。

## 六、后续批量方案

三种课型的样板至此齐了：`mt_sent-extend`（六段）、`mt_read-mark`（阅读五段）、
`mt_write-diary`（写作五段）。三课共用同一套第四代外壳与判分边界，
`docs/design/chinese/` 下的三份文档即为三种课型的**模板契约**。

其余 13 课按课型套用，优先级建议：

- **语言知识课**（六段）：`mt_punct-advanced`、`mt_sent-conjunction`、`mt_sent-quote`、
  `mt_oral-retell` —— 与 `mt_sent-extend` 同构，改题干与支架词即可。
- **阅读课**（五段）：`mt_read-predict`（三栏时间轴：我猜 / 因为 / 后来）、
  `mt_poem-understand` 与 `mt_read-ancient`（注释 ↔ 诗句 ↔ 画面三方对齐）、
  `mt_read-aloud`（只回放不评分）。
- **写作课**（五段）：`mt_write-observe`（感官清单 + 顺序轴，卡在搭骨架）、
  `mt_write-imagine`（清单换成矛盾检查，卡在改）、
  `mt_write-revise`（没有「写」，全程用旧文，难点是敢删）、
  `mt_char-writing`（写字，走 `writeChar`）、`mt_word-idiom`（成语故事，走 `story`）。

每课仍需：补 `standards`（9 课为空）→ 7 分片 → 构建/同步 → 100 分 → 结构测试 →
留痕迹链路 → 截图目视 → 语义期望表 → 设计文档 → Step 4 4A。
**样板阶段一律不做 4B**，等批量完成后统一发布，避免往 `links.json` 里塞零散链接。

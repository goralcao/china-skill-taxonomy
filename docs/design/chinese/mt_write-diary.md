# 语文样板课 03 · 学写日记（mt_write-diary，写作卷）

> 第四代交互式课件 · 小学语文 · 三年级 · 习作课
> 设计依据：`skills/k12-courseware/references/chinese-reading-writing.md` 第三节（写作五段）
> 同系列：`mt_sent-extend.md`（语言知识六段）、`mt_read-mark.md`（阅读五段）

## 一、为什么先做这一课

写作课与语言知识课、阅读课的产出物都不同：不是「改对的一处」，也不是「一条依据链」，
而是**一页能读的东西**；过关的实质是「写前想清楚、写后知道改哪」。共识稿 3.1 给了
五段骨架（起意 → 搭骨架 → 起草 → 改 → 出刊），3.2 列了三年级真正要改的四件事
（增 / 删 / 调 / 换），3.4 用一张表划清了「机器能做什么、不能做什么」。

`mt_write-diary` 是 16 课里最完整跑得通五段的一课：从零起意到出刊，五段一个不缺。
`mt_write-revise`（修改习作）是「全程用旧文、没有写」的特例，不适合当通用模板。
规范 3.3 还专门点明日记卡在「起意」，关键设计是「选材 + 日期/天气格式前置锁定」，
正好能验证「格式类前置」与「开放表达不拦路」怎么同时成立。
课标 `chinese-2022:S2:PR`，前置 `mt_write-imitate` / `mt_punct-basic`，
后续 `mt_write-narrative` / `mt_write-application`。

## 二、核心矛盾与解法：12 页里装下写作五段

仍按**判分边界分层**：唯一答案的习作方法知识进四套测验，五段开放表达一律不判分。

| 层 | 内容 | 判分 | 页面 |
|---|---|---|---|
| 唯一答案的习作方法知识 | 日记格式、选材、先撒后收、增删改调换、只给事实不给判断 | **判分** + 每题错因解析 | p1 / p4 / p7 / p9，共 14 题 |
| 开放表达 | 起意、搭骨架、起草、改、出刊 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

### 12 页与写作五段的映射

| 页 | 标签 | 五段 | 学生动作 | 过关的实质 |
|---|---|---|---|---|
| p0 | 封面 | — | 看见「8 张卡 → 三格 → 一页书」 | — |
| p1 | 前测 | — | 3 道：格式与选材 | 唯一答案，判分 |
| p2 | 起意 | ① 起意 | 8 张生活卡点进素材池 → 只收 1 张进主格 → 点 3 个想写的词 | 主格有卡 + 3 个词 |
| p3 | 搭骨架 | ② 搭骨架 | 3 条事件条可上移排序，每格填「这段要让人知道___」+ 点详略 | 每格都填了功能，不是一路「然后」 |
| p3b | 连一连 | （知识梳理） | 8 对「日记格式/做法 ↔ 它管的事」 | 唯一答案配对，不进 QUIZZES |
| p4 | 中测1 | — | 3 道：构思不能只给一个输入框 | 唯一答案，判分 |
| p5 | 起草 | ③ 起草 | 日期、天气填空条前置；三格输入，每格顶一句「这格写什么」 | 三格都有字（字数不限） |
| p6 | 改 | ④ 改 | Canvas 体检单：点一条 → 高亮可疑句 → 点中一句才打勾 | 至少改 3 处，改的是句子 |
| p7 | 中测2 | — | 3 道：增删改调换 vs 错别字 | 唯一答案，判分 |
| p8 | 出刊 | ⑤ 出刊 | 拼成「我的一页书」+ 署名 + 三条自查 + 发布 | 点发布，勾不满也放行 |
| p9 | 后测 | — | 5 道：写作的边界 | 唯一答案，判分 |
| p10 | 存起来 | — | V4 四卡 + 显示**自己写的一页书全文与署名** | 结算显示自己的产物 |

**「前置锁定」与「不拦路」怎么同时成立**：日期、天气做成填空条放在三格之上，
填了就显示「格式已定：10 月 12 日　雨」；没填也**照样能写三格**，只是提示一句。
共识稿说格式类可以前置给范例，但「开放表达永不给否定结论」更高优先，
所以做成「提示」而不是硬禁用。

**构思不能只给一个输入框**：p2 先「撒」（8 张卡随便点进素材池）再「收」
（只留 1 张进主格），另点 3 个「我还要写的词」。这 6 个候选词是**支架不是好词好句库**，
文案里明写「不是好词好句库，也不用抄」。

## 三、刻意不做的事（对照共识稿 3.4 / 3.5）

> 原则：**能给学生看的只有「事实」，不能给的是「判断」。**

| 检查 | 本课做法 |
|---|---|
| 字数达标 | 只说「三格写了 X / 3 行」，不说好坏 |
| 句数 / 平均句长、段落数 ≥ 3、每段首句是中心句 | 一律不显示（首句中心句误判很高，**禁止**） |
| 感官词、顺序词 / 「然后」计数、重复词频 | 作为体检单里的「事实」提示，不作评判 |
| 标点、是否抄题干 | 不进学生界面 |
| 「好词好句」词表命中、情感 / 立意评分 | **禁止**，页面明写不判情感、不判立意 |
| 先发范文再说「照着写」 | **不做**：p5 没有范文，p6 的 `simDemo()` 也是「先自己试一次，再看不迟」 |

两个「假写作」也避开：输入框旁挂好词好句库（教拼贴）、先发范文（教填空仿写）。
另外不做同伴互评、不做朗读打分、不做「X / Y 一次答对」、不做排行榜。
**错别字不属于「改」** —— 体检单 5 条全部落在句子上，后测第 9 题直接考这条。

## 四、仿真设计：体检单（Canvas）

`course.js` 里的 `simDraw()` 画一张左右工作台：左栏 3 段自编草稿
（含「然后 ×3」「连续我……开头」「只有动作没感觉」「很开心/很好玩」等毛病），
右栏 5 条体检清单，每条带一个动作色点（红删 / 绿增 / 蓝调 / 绿换）。

- **两步才算改过**：点清单只算「看到问题」（对应段变黄高亮），
  再点左边**任意一句**才记下一处改动；`simFixLine()` 把该句标绿并打勾。
  为了不判对错，点哪一句都允许打勾——规范要的是「点中一句才允许打勾」，
  不是「点中正确那句」。
- 读数写「**已改 X / 5 处（改的是句子，不是错别字）**」，不是分数。
- `simNextCase()` 换《早上的猫》另一组草稿，体检单还是 5 条；
  `simDemo()` 一次把 5 处都落在句子上，文案仍是「看老师改这一句」。
- 底部三条说明把 3.4 的边界写进课件：点中一句才算改过 /
  能给学生看的只有事实 / 不判情感不判立意不查好词好句。

### 修过的问题

1. Canvas 体检单必须先点清单再点句子，测试脚本最初只点一次所以读数不动；
   这是**设计如此**（两步留痕），补了双步点击测试确认 0→1 才记改动。
2. p6 沿用阅读课的紧凑规则（缩短说明、`padding-bottom:18px`），
   一次生成即全页 852px，没有出现溢出。
3. p8 出刊页与 p10 结算页在 `localStorage` 为空时显示「还没起草」的占位文案，
   写入后自动替换成学生自己的三格全文，符合「结算必须显示自己写的东西」。

## 六、后续批量方案

三种课型样板齐了，其余 **13 课**按课型套用（详见 `mt_read-mark.md` 第六节的完整清单）。
写作课里四个变体要各自调骨架：

| 课 | 卡在哪一段 | 关键改造 |
|---|---|---|
| `mt_write-observe` | 搭骨架 | 感官清单（看听摸闻）+ 顺序轴，不排完不许写 |
| `mt_write-imagine` | 改 | 体检单换成矛盾检查：「他之前说不会飞，后面怎么飞了？」 |
| `mt_write-revise` | 没有「写」 | 全程用旧文，难点是敢删；五段里「起草」换成「读旧文」 |
| `mt_char-writing` | 写字 | 走 `writeChar`，田字格描红，不做朗读打分 |

每课仍需：补 `standards` → 7 分片 → 构建/同步 → 100 分 → 结构测试 →
留痕迹链路 → 截图目视 → 语义期望表 → 设计文档 → Step 4 4A。
**样板阶段一律不做 4B**，等批量完成后统一 4B 发布 + 链接表 + 教师必看页 + 线上核验，
与数学 52 课的收尾口径保持一致。

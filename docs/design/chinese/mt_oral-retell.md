## 二、判分边界：12 页里装下语文六段

`chinese-design.md` 明确写了「**不要套数学的情境 → 探究 → 例题 → 练习 → 小结**」，
语文的过关是「**留下痕迹**」。调和方式是按判分边界分层：

| 层 | 内容 | 判不判分 | 落在哪几页 |
|---|---|---|---|
| 唯一答案的语言知识 | 本课 14 道题，每题带错因解析 | **判分** | p1 / p4 / p7 / p9 |
| 半开放（有规则可查） | 8 组连一连 | 连线组件判对错，不计分 | p3b |
| 开放表达 | 读进去、看出来、写下来、改一处、评一评 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

> 14 题全部设计成有唯一答案的语言知识题，不碰开放表达；每题答案分布收敛到
> `{0:5, 1:5, 2:4}`，避免学生靠「都选 B」蒙对。

## 四、本课变体：口语课的要点痕迹与占位块

本课把六段骨架用在**口语交际**上，产出物是「一句能照着做的传话」。
「看出来」圈的是通知里三样漏了就办不成事的信息（时间 / 地点 / 要带什么），
而不是句子成分——口语课要留的痕迹是**要点**，不是语法标签。

仿真是四槽要点台，四个槽之间夹着逗号；未填时句子区会显示成「老师说，，，，。」，
因此为本课启用了可选的灰色 `□` 占位块（`CN.phText`）与面板动词 `已记`
（`CN.panelAddedLabel`），其余三课不启用，行为不变。

## 五、Canvas 仿真：不判分，只留痕迹

仿真是「积木台」：点候选词块补进 `seq` 描述的句子，读数只报
「已添 X / N 处（不判对错）」，不给分数。三个案例：

- **集合通知**：4 个槽（时间 / 地点 / 事情 / 带什么）
- **交作业通知**：4 个槽（时间 / 地点 / 事情 / 带什么）
- **活动通知**：4 个槽（时间 / 地点 / 事情 / 带什么）

`simAdd / simDemo / simNextCase / simReset / simBind` 保持第四代结构测试契约；
`SIM.hits` 供 Canvas 点击命中；画布着色、连线 16 元素、V4 展开均纳入自动回归。

### 修过的问题

1. 中测一第 6 题「加一句『我觉得肯定特别好玩』算不算合格」发生
   **选项重排后 `answer` 未同步**：`answer=1` 指向「要看是谁说的」。
   语义抽核（按正确答案文本断言）抓出后交换 B/C 选项顺序修正，分布仍 `{0:5,1:5,2:4}`。
2. 四槽之间夹逗号，未填时句子区成「老师说，，，，。」，
   为本课启用灰色 `□` 占位块与面板动词「已记」。
3. 仿真说明过长导致 p6 溢出 873px，缩短到一行后回落 852。

## 二、判分边界：12 页里装下语文六段

`chinese-design.md` 明确写了「**不要套数学的情境 → 探究 → 例题 → 练习 → 小结**」，
语文的过关是「**留下痕迹**」。调和方式是按判分边界分层：

| 层 | 内容 | 判不判分 | 落在哪几页 |
|---|---|---|---|
| 唯一答案的拼音知识 | 本课 14 道题，每题带错因解析 | **判分** | p1 / p4 / p7 / p9 |
| 半开放（有规则可查） | 8 组连一连 | 连线组件判对错，不计分 | p3b |
| 开放表达 | 听一听、看一看、摆一摆、拼一拼、查一查 | **一律不判分**，只留痕迹 | p2 / p3 / p5 / p6 / p8 |

> 14 题全部设计成有唯一答案的拼音知识题，不碰开放表达；每题答案分布收敛到
> `{0:5, 1:5, 2:4}`，避免学生靠「都选 B」蒙对。题干压到一年级能读的短句，
> 字号、色块、按钮按一年级放大（`run_py.py` 的 EXTRA_CSS 覆盖层）。

## 四、本课变体：整体认读台「不拆开」

本课是 `CN.mode='whole'` 整体认读台：左卡「整体记，不拼」、中间一个带斜杠的
圆圈表示**禁止拆开**、右卡「它带出的字」。两个槽（音节 / 汉字）都只留痕迹，
`simCompose()` 只返回整块音节，不生成任何「拼」的中间态。

难点在**和拼读音节划清边界**：`p3` 圈的是 `zhi chi shi`，干扰项放 `ba`、`a`；
后测专门设了「下面哪一个不是整体认读音节」（`gua`）。16 与 23 这两个数字也
放进题里辨析，防止和声母个数记混。

## 五、Canvas 仿真：不判分，只留痕迹

仿真是「音节台」：点候选块补进 `CN.cases` 的槽里，读数只报
「已摆 X / N 处（不判对错）」，不给分数。`CN.mode = whole`，三个案例：

- **zhi chi shi ri**：2 个槽（选音节 / 配一个字）
- **yi wu yu**：2 个槽（选音节 / 配一个字）
- **zi ci si**：2 个槽（选音节 / 配一个字）

`simAdd / simDemo / simNextCase / simReset / simBind` 保持第四代结构测试契约；
`SIM.hits` 供 Canvas 点击命中；画布着色、连线 16 元素、V4 展开均纳入自动回归。
四个 mode 共用的绘制函数：`simOptLabel()` 把组合调号换成中文名、
`simToned()` 查表生成带调韵母、`simCompose()` 只负责展示不负责判定。

### 修过的问题

1. 开场标题「有一批音节，偏偏不用拼」既无数字也无问号，hook 记 0/5；
   改成「为什么偏偏不用拼？」并保留「10 秒钟」后回到满分。
2. 中间「不拆」文字与下方一长行说明挤在 y=150/158 两行，重叠；
   删掉文字只留带斜杠的圆圈，说明行缩短为三组音节名。
3. 第二槽 ask「选它带出的字」过长，压到第一个候选块；
   改成「配一个字」并把候选块起点移到 150。

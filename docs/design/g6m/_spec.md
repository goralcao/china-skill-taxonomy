## 2. 六年级认知跃迁

六年级的核心是**关系与模型**：比、比例、正反比例把「两个量一起变」变成可算的式子；百分数把分数搬到真实语境；圆柱圆锥把二维面积推到三维体积。设计上要抓两点：

- 每个关系都要有**两个量同时变**的可视化（表格 + 图像双呈现），不做单点计算；
- 公式给出前必须先有**一次测量或一次拼摆**，不直接抛 π、不直接抛 1/3。

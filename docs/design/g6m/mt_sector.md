## 4. 仿真机制

- 换一组角度，点「加大角度」看扇形怎么张开，右侧实时算出占比、面积与弧长。
- 顶点在圆心，两条半径夹出圆心角。
- 占比 = 圆心角 / 360°，面积与弧长都按这个比例取。
- 360° 是整个圆，180° 是半圆。
- 交互：① 加大角度、一键到底、换一组、重来；点画布推进。

## 5. 易错点与总结

辨析页「四个易错点，都在「360°」和「顶点」上」覆盖：
- 坑一：占比当角度：25% 画成 25° ✗ —— 要乘 360°：25% × 360° = 90°。
- 坑二：顶点不在圆心：角尖在圆内也算扇形 ✗ —— 顶点必须正好在圆心。
- 坑三：面积忘乘比例：90° 扇形面积直接写 πr² ✗ —— 要乘 90/360 = 1/4。
- 坑四：占比合计不对：各项加起来 95% 就画 ✗ —— 必须正好 100%、角度合计 360°。

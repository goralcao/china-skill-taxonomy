## 4. 仿真机制

- 换一组半径，点「加大半径」看圆怎么长，同时观察直径 d = 2r、半径条数、对称轴条数。
- 半径决定圆的大小，圆心决定圆的位置。
- 同一个圆里半径有无数条，且长度都相等。
- d = 2r 与半径取多少无关，始终成立。
- 交互：① 加大半径、一键到底、换一组、重来；点画布推进。

## 5. 易错点与总结

辨析页「四个易错点，都在「过不过圆心」和「无数条」上」覆盖：
- 坑一：弦当直径：两端在圆上就是直径 ✗ —— 还必须经过圆心；否则只是弦。
- 坑二：半径只有一条：一个圆只有 1 条半径 ✗ —— 圆上有无数个点，半径有无数条。
- 坑三：直径比半径大 2：d = r + 2 ✗ —— 是 d = 2r，两倍不是多 2。
- 坑四：对称轴数错：圆有 4 条对称轴 ✗ —— 正方形才是 4 条，圆有无数条。

V4 四卡：定义、d = 2r、都相等、对称与生活。

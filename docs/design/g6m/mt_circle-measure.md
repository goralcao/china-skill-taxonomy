## 4. 仿真机制

- 换一个半径，按「滚一圈 → 切成小份 → 拼成长方形 → 读出 C 与 S」一步步看，切得越细拼得越像长方形。
- 滚一圈走过的长度就是周长 C = 2πr。
- 长方形长 ≈ 半周长 πr，宽 = r。
- S = πr × r = πr²；周长用长度单位，面积用平方单位。
- 交互：① 下一步、一键到底、换半径、重来；点画布推进。

## 5. 易错点与总结

辨析页「四个易错点，都在「平方」和「单位」上」覆盖：
- 坑一：r² 当成 2r：r = 3 时 πr² 算成 3.14×6 ✗ —— r² = 3×3 = 9，应是 3.14×9 = 28.26。
- 坑二：单位写错：面积写成 12.56 厘米 ✗ —— 面积要用平方厘米、平方米。
- 坑三：半圆周长漏直径：半圆周长 = πr ✗ —— 还要加一条直径：πr + 2r。
- 坑四：直径直接代入 r：d = 10 就算 π×10² ✗ —— 先求 r = 5，再算 π×5²。

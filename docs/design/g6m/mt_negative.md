## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 零下 5℃ 和零上 5℃，差在哪里？ |
| 冲突 | 生活中有一对一对意义相反的量：零上和零下、收入和支出、上升和下降。只写「5 度」「200 元」分不清方向。 |
| 落点 | 负数的价值在于给方向编了个号：先定「以谁为 0」，再定「哪边为正」，相反方向自然就是负。 |

## 4. 仿真机制

- 换一个起点，点「向左 / 向右」在数轴上移动，右侧实时显示当前数、与 0 的距离和大小比较。
- 0 是分界，既不是正数也不是负数。
- 负数离 0 越远，数值越小：−8 < −3。
- 正数可省略 + 号，负数的 − 号不能省。
- 交互：① 向左 1 格、向右 1 格、换起点、重来；点画布推进。

## 5. 易错点与总结

辨析页「四个易错点，都在「0」和「负号」上」覆盖：
- 坑一：0 算正数：0 是正数 ✗ —— 0 是分界，不正也不负。
- 坑二：漏负号：零下 5 度写成 5℃ ✗ —— 必须写 −5℃，否则意思反了。
- 坑三：按数字比大小：−8 > −3 因为 8 > 3 ✗ —— 数轴上 −8 更靠左，−8 < −3。
- 坑四：方向搞反：向左走数变大 ✗ —— 数轴向右为正，越往右数越大。

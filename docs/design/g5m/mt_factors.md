## 3. 仿真 spec

```
Name:        摆一摆，12 块方糖能摆出几种长方形
Goal:        「12 的因数只有 1、2、3」「块数越多因数越多」
Mechanism:   换个数（12/16/18/24/36/48）+ 逐个摆法 + 一次列全
Parameters:  6 个总数 × 每个数的全部因数对
Visual:      琥珀色方糖网格 + 右侧因数对列表（当前项玫红高亮）+ 底部算式
Feedback:    每换一种就报「12 ÷ 3 = 4，3 和 4 是 12 的因数」；4×4 时提示「只算一次」
Boundaries:  转个身算同一种；1×n 时格子自动缩小不留白
Expected:    学生自己数出摆法数 = 因数对，且发现 16 的因数是 5 个（奇数）
```

## 4. 易错

1. 把「因数」「倍数」说反（12 是 3 的因数）；
2. 找因数只找到一半就停（12 只写 1、2、3）；
3. 漏掉 1，以为从 2 开始；
4. 以为一个数有最大的倍数。

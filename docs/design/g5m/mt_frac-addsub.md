## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 一盒蛋糕切成 8 块，哥哥吃 3 块、妹妹吃 2 块，一共 5 块 |

## 3. 仿真 spec

```
Name:        分数条拼接：换个题，先通分再加
Goal:        「分母不同就不能直接数格子」「通分只换写法不换大小」
Mechanism:   ① 通分（按 lcm 重切两条）→ ② 相加（结果条涂色）→ 换一组 / 重来
Parameters:  6 组算式：3/8+2/8、1/4+1/6、2/3+1/4、3/10+1/2、5/6+1/3、1/2+1/8
Visual:      左侧三条分数条（原始两条 + 结果条），右侧算式 / 公分母 / 结果 / 最简分数面板
Feedback:    每次操作写日志，如「通分：公分母 12，两个分数变成 3/12 和 2/12」
Boundaries:  分母本来就相同的组（3/8+2/8）不要求通分，直接可相加；
             点画布左半区按状态推进，点右半区换下一组
Expected:    学生发现「格子一样宽才能数」，且结果能约分时面板同时给出最简分数
```

## 4. 易错

1. 分母也相加（3/8 + 2/8 = 5/16）；
2. 只改分母不改分子（1/4 化成 1/8）；
3. 结果忘了约分（4/8 直接交卷）；
4. 减法里分子分母各自相减（5/6 − 1/3 = 4/3）。

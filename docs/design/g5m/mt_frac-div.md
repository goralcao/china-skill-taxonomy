## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 3 个饼分 4 人，一人一整个不够 |
| 冲突 | 3 ÷ 4 除不尽，余数又不能再分 |
| 落点 | 每个饼切 4 份 → 3 ÷ 4 = 3/4；被除数当分子、除数当分母 |

## 3. 仿真 spec

```
Name:        分饼：几个饼分给几个人，每人几个
Goal:        「除不尽就没法分」「把被除数除数放反」
Mechanism:   饼 +1（1–5）、人 +1（2–8）、重来
Parameters:  5 档饼数 × 7 档人数
Visual:      n 个圆饼各自切成 m 份（第 1 份涂黄）+ 右侧真分数 + 除法算式
Feedback:    每次改动报「4 ÷ 5 = 4/5 个，每饼要切 5 份」
Boundaries:  饼最多 5 个、人最多 8 个；饼数>人数提示「每人超过一个」
Expected:    学生发现「饼数当分子、人数当分母」，且饼少人多时答案小于 1
```

## 4. 易错

1. 上下放反（3÷4 写成 4/3）；
2. 分母写 0（5÷0 = 5/0）；
3. 「A 是 B 的几分之几」用错被除数；
4. 「占几分之几」和「几米」两个问法混答。

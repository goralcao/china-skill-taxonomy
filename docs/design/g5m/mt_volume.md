## 3. 仿真 spec

```
Name:        一层一层填：看体积怎么累出来
Goal:        「体积 = 长×宽×高」「每层块数 × 层数」
Mechanism:   ① 加一层 / 一次填满 / 换尺寸 / 重来；点画布 = 加一层
Parameters:  5 组尺寸 4×3×2、5×4×3、3×3×3、6×2×2、2×2×4（单位 cm）
Visual:      等轴测长方体线框 + 逐层填充的单位立方体（按层配色），
             长/宽/高标注，右侧每层块数、已填层数、已用方块、总体积与 dm³/mL/L 换算
Feedback:    每次加层写日志「加第 1 层：多 12 块，累计 12 cm³」
Boundaries:  层数不超过高；填满后提示换尺寸
Expected:    学生发现「每层块数 × 层数」恒等于长×宽×高，且 1000 cm³ 才等于 1 L
```

## 4. 易错

1. 把体积进率记成 100（面积才是 100）；
2. 长宽高单位不统一就直接相乘；
3. 从外面量尺寸去算能装多少水（容积要从里面量）；
4. 把 1 L 当成 1000 dm³（实际 1 L = 1 dm³ = 1000 mL）。

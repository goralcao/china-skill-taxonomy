## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 8 格转盘 1 格中奖，转 40 次「应该」中 5 次 |

| 落点 | 可能性看份数，验证看次数；可能 ≠ 一定 |

## 3. 仿真 spec

```
Name:        转起来，看实际中几次
Goal:        「8 次一定中 1 次」「可能性小就是不可能」
Mechanism:   金色格数可 ±1；按转 1 / 100 / 1000 次，右侧实时统计次数与百分比
Parameters:  金色 0–8 格；次数 1 / 100 / 1000
Visual:      8 格转盘（指针正对 1 号格）+ 红/紫双柱 + 橙色理论虚线
Feedback:    柱长与百分比随次数变化；提示「次数太少还在乱跳」「已贴住理论值」
Boundaries:  金色只能在 0–8；改格数时统计清零
Expected:    学生发现次数越多越贴近 12.5%，10 次时乱跳得厉害
```

## 4. 易错

1. 转几次没中就下结论；
2. 可能性小当成不可能；
3. 以为转 8 次一定中 1 次；
4. 以为先转的人占便宜。

# 折线统计图 · 一周气温从 18℃ 升到 26℃，哪天升得最快？

## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 连续 7 天 7:30 测气温：18、20、19、23、26、24、21℃ |
| 冲突 | 最高点是周五，但升得最快的却是周三→周四 |
| 落点 | 点读数量、线读变化、陡读快慢；最高 ≠ 变化最快 |

## 3. 仿真 spec

```
Name:        改一天的数据，看折线怎么变
Goal:        「点高不等于变化快」「折线随数据重绘」
Mechanism:   点画布选中某一天 → 升高 / 降低选中日 → 换一组数据 / 重来
Parameters:  4 组数据集（一周气温、一周最高温、小店日销量、每日跳绳），
             每组 7 天 × 各自的 lo/hi/step
Visual:      左侧折线图（网格、面积、点、选中日竖虚线 + 数值标注），
             右侧面板（选中日数值、与前一日差、最高/最低、升得最快段、整体趋势）
Feedback:    每次改动写日志，折线与面板结论同步重算
Boundaries:  升高不超过该组 hi、降低不低于 lo；点画布绘图区外不响应
Expected:    学生发现「抬高某天后最陡的一段会换」，且最高点与升得最快是两回事
```

## 4. 易错

1. 把点的高低当成变化快慢（周五最高 ≠ 升得最快）；
2. 折线图只当条形图比大小，忽略线段的升降；
3. 连线时按数值大小排序，而不是按日期先后；
4. 不看纵轴每格代表多少，误判线的陡缓。

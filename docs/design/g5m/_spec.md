## 2. 五年级认知跃迁

四年级以「认与算」为主，五年级开始出现**关系**（因数与倍数、分数与除法、比与比例雏形）和**转化**（割补、通分、三分法）。设计上要抓两点：

- 每个新概念必须有一个**可操作的转化动作**（割一刀、通一次分、换一次单位），不做纯符号推演；
- 结论要能反推回学生熟悉的数量关系（如 3÷4 = 3/4 块饼）。

# 约分与通分 · 24 块吃掉 18 块，为什么等于吃了 3/4？

## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 24 小块吃掉 18 块，写成 18/24，可它就是 3/4 |
| 冲突 | 数字都变了，凭什么说一样大 |
| 落点 | 分子分母同乘同除，大小不变 → 约分到互质、通分到同分母 |

## 3. 仿真 spec

```
Name:        一刀一刀约下去，看分数怎么变小
Goal:        「数字变了分数就变了」「除到一半就算最简」
Mechanism:   同时 ÷2 / ÷3 / 一次除到底 / 换个分数 / 还原
Parameters:  5 组（18/24、12/18、16/24、24/36、30/42）
Visual:      整条 = 单位「1」的分格长条 + 涂色段 + 橙色长度标记 + 大分数
Feedback:    每次除报「18 ÷ 2 = 9，24 ÷ 2 = 12 → 9/12，条子长度一点没变」
Boundaries:  除不尽时提示「切不整齐」；互质时提示「已经最简」
Expected:    学生看到格数变少、每格变大，而涂色长度始终停在同一条虚线上
```

## 4. 易错

1. 只除分子不除分母；
2. 通分时只乘分母不乘分子；
3. 约到一半就停（16/24 写成 8/12）；
4. 公分母乱取 24 而不是最小公倍数 12。

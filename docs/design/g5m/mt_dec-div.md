## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 40.5 元三人分，整元分完还剩 1 元 |
| 冲突 | 余下的 1 元不能扔，也不能让一个人多拿 |
| 落点 | 余数换成更小的单位继续分；商的小数点跟被除数对齐；除数带小数时两边同时扩大 |

## 3. 仿真 spec

```
Name:        用 0.9 米的一段量 7.2 米
Goal:        「除数带小数就没法除」「商是猜的」
Mechanism:   彩带按 0.1 米切格，按「量一段」把 0.9 米接上去；也可点彩带直接跳
Parameters:  6 组（7.2÷0.9、4.5÷0.9、3.6÷1.2、2.4÷0.6、5.4÷0.6、1.5÷0.5）
Visual:      彩带 72 小格（每 10 格标 1 米）+ 下方分段色块 + 右侧段数与剩余
Feedback:    接满时提示「正好量完」，底部等式显示 72÷9=8
Boundaries:  接不下时提示「剩下的不到一段」；退到 0 不再退
Expected:    学生发现 7.2÷0.9 与 72÷9 同解，商就是段数
```

## 4. 易错

1. 只把除数变整数，被除数不变；
2. 商的小数点没对齐，13.5 写成 1.35；
3. 余数比除数还大，商调小了；
4. 商中间的 0 漏写（4.02÷2 写成 2.1）。

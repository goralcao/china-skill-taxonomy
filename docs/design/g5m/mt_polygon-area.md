## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 平行四边形菜地底 6 米、高 4 米，怎么算面积 |
| 冲突 | 直接乘斜边会偏大；格子又数不清 |
| 落点 | 沿高剪一刀平移成长方形 → 底 × 高；三角形、梯形都是它的一半 |

## 3. 仿真 spec

```
Name:        剪一刀，挪过去，看它变成长方形
Goal:        「面积会变」「底 × 斜边也行」
Mechanism:   按「剪一刀」切下左三角形，按「挪过去」平移到右侧；可显示 1 米格线
Parameters:  4 组（6×4、8×5、3×7、10×4），倾斜固定
Visual:      绿色梯形 + 橙色三角形 + 灰色虚框长方形 + 底/高标注与直角记号
Feedback:    平移过程中箭头提示方向；到位后提示「长方形：6 × 4 = 24」
Boundaries:  未剪不能挪；重复剪给出提示
Expected:    学生看到拼好后长方形的长就是底、宽就是高
```

## 4. 易错

1. 底 × 斜边（6×5=30）；
2. 三角形忘 ÷2；
3. 梯形忘 ÷2；
4. 沿斜边量高，量出的是斜边不是垂直距离。

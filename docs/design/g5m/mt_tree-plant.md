## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 20 米路每 5 米一棵、两端都栽，要几棵 |
| 冲突 | 20 ÷ 5 = 4，可树是 5 棵 |
| 落点 | 先求间隔数，再看两端栽不栽（+1 / 0 / −1） |

## 3. 仿真 spec

```
Name:        在路上一棵一棵摆出来
Goal:        「20 ÷ 5 = 4 棵」忘了末端那一棵
Mechanism:   改间隔（2/4/5/10 米）、改栽法（两端/一端/都不栽）、换路长（20/30/40/50 米）
Parameters:  4 条路 × 4 种间隔 × 3 种栽法
Visual:      路 + 树 + 间隔刻度与编号 + 底部「间隔数 → 棵数」算式
Feedback:    棵数实时变化；空着的端点标「空」；日志记录每次改动
Boundaries:  棵数最少 3 棵；间隔过小时只标偶数刻度避免拥挤
Expected:    学生发现间隔数只看总长与间隔，棵数只是加减
```

## 4. 易错

1. 忘了加 1（20 ÷ 5 = 4 棵）；
2. 段数当棵数；
3. 围成一圈还算 +1；
4. 米与分米混着除。

## 3. 仿真 spec

```
Name:        小数点挪回家
Goal:        「整数乘完就完事」——忘了按位数归位
Mechanism:   画布中央给出整数积的数字串，红点默认在最右；按「左移一位」或直接点数字之间的缝
Parameters:  6 个案例（0.8×25、2.5×4、1.2×5、0.15×4、2.5×3.5、0.2×0.3），位数 1–2 位
Visual:      顶部整数算式 + 中央大数字串与缝 + 底部三块读数（位置 / 现在的积 / 该点几位）
Feedback:    挪对 → 读数变绿、提示「对上了」；挪错 → 红点 + 差几位
Boundaries:  最多挪 4 位；k=0 时不能再右移
Expected:    学生发现 0.15×4 要比 0.8×25 多挪一位，0.2×0.3 还要补一个 0
```

## 4. 易错

1. 像加法一样对齐小数点；
2. 位数取两个因数里多的那个；
3. `0.2 × 0.3` 写成 6，忘了补 0；
4. 算出 200 就交卷，不估大小。

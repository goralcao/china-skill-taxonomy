## 3. 仿真 spec

```
Name:        天平分组模拟：换数量、换分法，比谁称得少
Goal:        「平均三份最省」「次数按 3 的幂增长」
Mechanism:   ① 称一次（按当前分法把嫌疑缩到一份）→ 切成 3 份 / 切成 2 份对照 → 换数量 / 重来
Parameters:  4 档数量 3 / 9 / 27 / 81 瓶，2 种分法（3 份最优、2 份对照）
Visual:      天平横梁按结果倾斜、两份上秤托盘 + 右上「第 3 份·不上秤」框、
             底部嫌疑范围进度条、右侧数量/分法/已称次数/理论最少次数面板
Feedback:    每次称量写日志「第 1 次：分成 3、3、3，次品落在第 2 份，嫌疑 9 → 3 瓶」
Boundaries:  候选只剩 1 瓶即判定找到；点画布任意位置 = 称一次
Expected:    学生对比发现切成 2 份时理论次数明显变多（9 瓶 4 次 vs 3 份 2 次）
```

## 4. 易错

1. 分成两份（浪费天平的第三种结果）；
2. 三份不平均（1、1、7 平衡时最坏留 7 瓶）；
3. 只按运气好的那支数次数，不按最坏情况；
4. 不知道次品是轻还是重，就说「翘起那边是次品」。

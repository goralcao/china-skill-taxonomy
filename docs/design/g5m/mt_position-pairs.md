## 3. 仿真 spec

```
Name:        按数对找格子
Goal:        「先写行后写列」「(3,2) 和 (2,3) 一样」两个错念头
Mechanism:   给目标数对，点方格纸；点错落地痕迹并说明差列还是差行
Parameters:  8 列 × 6 行固定，6 个目标数对轮换
Visual:      格线 + 列号（下）+ 行号（左）+ 目标条 + 绿/红落点
Feedback:    对 → 绿底并写出 (c,r)；错 → 红底 + 「行数对了，列数差 N 格」
Boundaries:  点格外出界不响应；提示可开关
Expected:    学生发现列变行不变是同排移动，(3,4) 与 (4,3) 隔着一条对角线
```

## 4. 易错

1. 先写行后写列（票上「8 排 5 号」写成 (8,5)）；
2. 行从上往下数，把第 1 行数成最后一排；
3. 逗号写成小数点 (3.2)；
4. 以为 (3,2) 与 (2,3) 是同一格。

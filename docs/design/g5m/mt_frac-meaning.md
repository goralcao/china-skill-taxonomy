## 1. 主线

| 环节 | 一句话 |
|---|---|
| 现象 | 一个蛋糕的 1/4 是一块，8 颗糖的 1/4 是 2 颗 |
| 冲突 | 都写 1/4，凭什么大小不一样 |
| 落点 | 单位「1」不同；分母管份数、分子管取几份；分母越大每份越小 |

## 3. 仿真 spec

```
Name:        分一分：一堆糖的几分之几是多少颗
Goal:        「3/4 就是 3 颗」「分母越大每份越大」
Mechanism:   换总数（12/8/6/18/20/24/15）+ 份数 +1 + 多取一份 + 重来
Parameters:  7 个总数 × 可整除的份数（2–6）× 取 1…份数
Visual:      一列 = 一份的糖阵 + 琥珀高亮已取组 + 右侧真分数面板
Feedback:    每次改动报「取 3 份：写作 3/4，实际是 9 颗」
Boundaries:  份数跳过不能整除总值的数；取满后自动回到 1；点右侧面板换总数
Expected:    学生发现分子是份数不是颗数，且 1/3 的 4 颗 > 1/4 的 3 颗
```

## 4. 易错

1. 不平均分也叫分数（随手掰一块说 1/4）；
2. 分子分母说反（5/6 说成分成 5 份）；
3. 以为分母越大分数越大（1/6 > 1/4）；
4. 以为单位「1」只能是一个物体。

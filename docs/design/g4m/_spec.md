## 2. 文案规则

- 标题只说「要解决什么」，不写「第 X 课时」「本课学习目标」
- 正文第二人称、短句，每段 ≤3 行
- 每页至少 1 个具体数字或具体物，禁用「本节课」「我们一起来」「让我们一起」「众所周知」「同学们」
- 引入页现象篇幅 ≤ 全页 30%，随即进入知识
- 讲授页不超过 3 行纯文字而无图（图走内联 SVG）

## 3. 测验规则

- 题型只有单选 / 多选；连线与分类只用于讲授页巩固
- 前测四要素：已有经验 / 暴露前概念 / 关联本课新知 / 情境喜闻乐见
- 同一测验内正确项位置必须打散（跑 `quiz-answer-check.js` 须 PASS）
- 后测至少 1 道迁移题：「用今天学的解释你身边的 ___」
- 每题必配 `explain`，说清「为什么错的那个选项会有人选」
- 每课固定 14 题：前测 3 + 中测 3×2 + 后测 5

## 4. 仿真 spec 模板

```
Name:        一句话说清这是什么
Goal:        学生脑子里的哪个错念头
Mechanism:   学生怎么操作，系统怎么响应
Parameters:  可调的量与范围
Visual:      画面上出现什么（表盘/格阵/数轴/地图）
Feedback:    操作后什么变了（颜色/数字/提示）
Boundaries:  边界与异常
Expected:    学生应该发现什么
```

## 5. 四年级学情画像（硬规约 #16）

## 7. 逐课设计文件

每课在开发到该课时先产出 `docs/design/g4m/<topicId>.md`，再写 7 个分片，避免一次写 20 份后大面积返工。

分片源码在 `scripts/skill-course/src/<topicId>/`，构建跑 `python3 scripts/skill-course/build_course.py <topicId>`，同步 viz 跑 `python3 /tmp/sync_one.py <topicId>`。

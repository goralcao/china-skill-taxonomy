## 一、主线：把「末尾对齐」和「小数点对齐」摆在一起比

| 环节 | 情境 | 学生的动作 |

| 开场 | 文具小票：笔记本 6.8 元、中性笔 2.45 元，付 10 元 | 发现照整数竖式末尾对齐会算出 3.13 元，比一支笔还便宜 |

| 规则 | 小数点是个位与十分位的分界，两点一齐则整张数位表自动对齐 | 把 6.8 补成 6.80，四列各对各的 |
| 迁移 | 8 − 2.35 连续退位、12.4 + 5.86 进位、10 − 3.7 补零 | 从最低位往左一列一列算，学会借位过桥与进位写小 1 |
| 收束 | 6.80 + 2.45 = 9.25，付 10 元找回 0.75 元 | 用 9.25 + 0.75 = 10.00 逆运算验算 |

## 三、仿真 spec

**机制**：四个数位槽固定 `COLX = [90, 150, 228, 288]`（十位 / 个位 / 十分位 / 百分位），小数点固定 `DOTX = 189`。所有例题统一补 0 成四位数组，`mode = 0` 末尾对齐、`mode = 1` 小数点对齐；`step = 0~n` 从百分位往左逐列算。

- `mode=0` 时第二行整体右移 `SHIFT=66`，数字改红色 `#C62828`，并额外画第 5 个淡红列底（标题「多 1 列」）—— 第二行最右那位正好落进去，直观看到「比第一行多占一列」
- 两条红色虚线分别画在 `DOTX` 与 `DOTX+66`，中间就是错开的 1 位；`mode=1` 只留一条青色虚线，标注「✓ 三点一线」
- 结果行：`mode=0` 只写「数位没对上，先别动笔」；`mode=1` 按 `step` 从右往左逐列显示得数，当前列橙框、已算列绿色，算完显示 `= 9.25`
- 右区两个可点模式按钮（末尾对齐 / 小数点对齐）+ 步骤列表；点某一步骤行可直接跳到该列，点任一橙色小数点圆点可切换模式
- `simNext()` 在 `mode=0` 时会先自动切到对齐态并提示「还没对齐就要动笔」，保证按钮永远有反馈
- 四道题的 `steps[]` 预定义为文本（不写通用计算器），避免连续退位/进位算错

| 案例 | 算式 | 得数 | 列数 | 训练点 |
| --- | --- | --- | --- | --- |
| 文具小票 · 加法补 0 | 6.80 + 2.45 | 9.25 | 3 | 补 0、十分位进位 |
| 找零 · 连续退位 | 8.00 − 2.35 | 5.65 | 3 | 8 → 7 / 0 → 9 / 0 → 10 借位链 |
| 两段绳子 · 加法进位 | 12.40 + 5.86 | 18.26 | 4 | 十位也参与、进位进对列 |
| 整数减小数 · 补 0 退位 | 10.00 − 3.70 | 6.30 | 4 | 10 补成 10.00、末尾 0 可化简成 6.3 |

函数：`simMode / simNext / simPrev / simCase / simReset / simDemo / simDraw / simLog / simBind / simRefresh`；`simCase()` 无参循环下一题，换题后回到「末尾对齐」未算态；`simDemo()` 用 700ms 定时逐列自动演示；`simBind()` 用 `cv.__simBound` 防重复绑定，坐标按 `getBoundingClientRect` 反算回 880×360。

## 四、易错点

1. **照整数末尾对齐**：8 个 0.1 撞上 5 个 0.01，算出 3.13 元。补成 6.80 再按小数点对齐才对。
2. **没补 0 就硬退位**：8 − 2.35 把 0 − 5 当成 5 直接落下，得 6.35。8 要写成 8.00，借位才有路可走。
3. **得数小数点乱落**：9.25 写成 92.5。小数点必须从上面直直落下来，跟两个加数排同一条竖线。
4. **补 0 补错位置**：6.8 写成 6.08。0 只能添在小数末尾，插到中间数就变了。

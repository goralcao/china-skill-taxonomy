## 仿真 spec

```
Name:        数位表拨珠
Goal:        学生以为「位数多就是读不出来」，其实是没按级分
Mechanism:   每个数位上方 ↑↓ 点一次加/减 1，0→9 循环；右侧实时显示读法与写法
Parameters:  12 个数位（亿级 4 + 万级 4 + 个级 4），每位 0–9
Visual:      三组色块分级的数位表，分级线加粗
Feedback:    读法文字随每一位变化；连续 0 只读一个「零」
Boundaries:  全 0 显示「零」；最高位为 0 时不读
Expected:    学生发现「0 不是每个都读」，级尾的 0 一个也不读
```

## 题库（14 题）

答案位：前测 `[1,0,0]` · 中测 1 `[0,1,1]` · 中测 2 `[0,1,0]` · 后测 `[0,1,2,2,1]`

**前测**（只考已有经验，不出现「亿」「数位表」等术语）

1. 全校 1200 人，这里的「2」表示什么？ A 2 个十 · **B 2 个百** · C 2 个千
2. 手机存储 128 GB，128 里的「1」在什么位？ **A 百位** · B 十位 · C 千位
3. 一万是几个一千？ **A 10 个** · B 100 个 · C 1000 个

**中测 1**（数位与计数单位）

1. 从右边起，第五位是什么位？ **A 万位** · B 千位 · C 十万位
2. 10 个一千万是？ A 一千万 · **B 一亿** · C 十亿
3. 最高位是百万位的数，是几位数？ A 六位 · **B 七位** · C 八位

**中测 2**（读写与改写）

1. 4005 读作？ **A 四千零五** · B 四千五 · C 四千零零五
2. 八十万写作？ A 80000 · **B 800000** · C 8000000
3. 3200000 改写成用「万」作单位？ **A 320 万** · B 32 万 · C 3200 万

**后测**（5 题，末题迁移）

1. 十万里面有 10 个（ ）。 **A 万** · B 千 · C 百万
2. 60600000 读作（ ）。 A 六千六百万 · **B 六千零六十万** · C 六千零六万
3. 由 5 个亿、3 个万组成的数是（ ）。 A 50030000 · B 500003000 · **C 500030000**
4. 1200000000 用「亿」作单位是（ ）。 A 1.2 亿 · B 120 亿 · **C 12 亿**
5. （迁移）短视频播放量 1 亿 2000 万，写成数字是（ ）。 A 120000000 · **B 1200000000** · C 12000000

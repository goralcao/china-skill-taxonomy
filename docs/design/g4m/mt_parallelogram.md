## 三、仿真 spec

**机制**：顶点可移，实时判定两组对边是否平行。

- 底边固定 320 px（80 厘米），上边 y 固定，高恒为 156 px（39 厘米）
- **平行四边形模式**：上边与底边等长（320 px），整体右移 `skew ∈ [20,160]` px；左腰、右腰向量相同 → 两组对边始终平行
- **梯形模式**：上边居中缩短 `topW ∈ [120,300]` px（30–75 厘米），两腰向量不同 → 只有一组平行
- 判定算法：`|(D.x-A.x) - (C.x-B.x)| < 0.6` 即两腰平行；上边下边恒水平
- 右侧面板实时打勾/打叉，并给出「→ 平行四边形 / → 梯形」结论
- 按钮：上边左移 / 右移 / 变短 / 变长 / 切换模式 / 重置
- 错按模式时给提示而不是静默无效（梯形模式下点「右移」会提示先切换）

## 五、易错点落位

1. **丢了「只有」** → p2 关键框强调「只有两个字不能丢」，p8 首卡专讲
2. **高画成斜的** → p3 直角符号 + p6 黄色虚线带直角标记
3. **以为底只有一条** → p3 规则①「四条边任选一组对边都能当底」
4. **把正方形排除在外** → p2 第三卡 + p8 第四卡

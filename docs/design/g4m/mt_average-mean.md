# 第 18 课 · 平均数（mt_average-mean）

> 12 页 / 14 题 / 1 个 Canvas 仿真 · 主色 `#006064` 深青 · 辅色 `#FF8F00` 橙（专标平均线与总数）· renderer `mean` · 认知动作 `累积`

## 一、主线：从「比总数不公平」到「削平后的那条线」

| 环节 | 情境 | 学生的动作 |
| --- | --- | --- |
| 开场 | 3 分钟跳绳，4 人 96 / 112 / 88 / 104 下，别组只有 3 人 | 发现人数不同不能直接比总数 |
| 直观 | 112 匀 12 给 88、104 匀 4 给 96，四根柱子都停在 100 | 认出「移多补少」削平后的高度就是平均数 |
| 算法 | 先合起来 400，再分成 4 份 | 得到 `平均数 = 总数 ÷ 份数`，并用 `100 × 4 = 400` 验算 |
| 脾气 | 20/22/18/40 平均 25，换成 100 后平均跳到 40 | 认出极端值会把平均数拉走，但平均数永远在最小与最大之间 |
| 收束 | 96/112/88/104 与 80/120/70/130 总和都是 400 | 数怎么挪不影响平均，只有总和与份数说了算 |

## 三、仿真 spec

**机制**：四根柱子 `BX = [70,170,270,370]`、宽 64、基线 `BASE = 280`，柱高按 `SCALE = 175 / max(数据)` 自适应，保证每组都填满画布；平均线 `y = BASE − 平均 × SCALE`。`step = 0~4` 五阶段：

| step | 画面 | 右侧步骤条 |
| --- | --- | --- |
| 0 | 四根高低不齐的青柱，柱顶标数值，选中柱橙框 | 第 1 条当前 |
| 1 | 底部出现橙色总数条 `总数 400 = 四根加起来` | 第 2 条「求总数」 |
| 2 | 橙色虚线平均线 + `平均 100` | 第 3 条「数份数」 |
| 3 | 高于线的部分红色框「多 +20 / 多 +30」，低于线的部分绿色框「补 +20 / 补 +30」 | 第 4 条「平均数」 |
| 4 | 四根橙柱齐平在平均线，原高度留淡灰虚线，四步全绿打勾 | 结论框「削平后每根都是 100」 |

- `simBump()` 给选中柱 `+4`（4 个数保证整除），总数与平均线同步上移 1，`simTip` 实时变成 `总数 404 · 4 人 · 平均 101`
- `simPick(k)` 点任意柱子选中；`simCase()` 换组时把 `SIM.vals` 重置为案例原始副本，`simReset()`  likewise
- 四组数据：`80/120/70/130`（400→100）、`18/24/15/23`（80→20）、`30/45/25/40`（140→35）、`20/22/18/100`（160→40，展示极端值）
- `step=3` 时**隐藏柱顶数值**，把位置让给「多 / 补」标注（否则 `补 +20` 会与 `80` 叠在一起）

函数：`simNext / simPrev / simBump / simPick / simCase / simReset / simDemo / simDraw / simLog / simBind / simRefresh`；`simDemo()` 700ms 定时推进到 step 4；`simBind()` 用 `cv.__simBound` 防重复绑定，坐标按 `getBoundingClientRect` 反算回 880×360。

## 四、易错点

1. **拿最大数当平均**：130 只是一个人，削平后是 100，平均数一定不超过最大数。
2. **除以最大数**：份数是「一共几个数」，4 个人就除以 4，和数据本身多大无关。
3. **人数不同还比总数**：人多自然总数大，要比平均数才公平。
4. **以为是某人的真实成绩**：100 是削平后的代表值，96/112/88/104 里谁都不是 100。

## 五、验收

- 12 页零横溢，14 题四测验全对（`pre [1,1,1]`、`mid1 [1,1,1]`、`mid2 [1,2,1]`、`post [1,2,1,1,2]`）
- 连线 16 个可点元素，右列 8 个答案互不相同（4 / 20 / 5 / 3 / 10 / 6 / 9 / 100）
- 仿真读数：`原始数据：80 / 120 / 70 / 130` → `合成总数 … = 400` → `平均线画好了：400 ÷ 4 = 100` → `移多补少：多出的正好补上缺的` → `四根齐平，平均数就是 100`；`simBump` 后变 101；`simPrev` 退回；`simCase` 换到 `18/24/15/23`
- 五种状态目视核对：step 0 原始、step 2 平均线、step 3 移多补少、step 4 齐平、极端值组 20/22/18/100 平均 40（结论框「平均在 18 ~ 100 之间」）
- 画布点击实测：点第 4 根柱 `k=3` → `simBump()` 数据变 `80/120/70/134`、平均 101、`simTip` 同步 → `simCase(3)` 换到极端值组平均 40。控制台 0 错误
- V4 首卡 `opacity = 1`
- 评分 100（课标 `math-2022:S2:SP`，前置 `mt_div-1digit` / `mt_stats-table` / `mt_bar-chart`，后续 `mt_stats-center` 与图谱出边一致）

**踩过的坑**：① `step=3` 时「补 +N」标注位置正好压住柱顶数值（低于平均线的柱子，`(top+avgY)/2` 与 `top−8` 几乎重合），改为该阶段隐藏柱顶数值；② 低于平均线的柱子若用 `avgY − top` 作矩形高度会得到负值，改成从 `avgY` 往下画 `top − avgY`；③ 按钮文案从「加 2」改为「加 4」，保证 4 个数时平均数每次只上移 1、不出现小数，正文与思考题里的数字同步改。

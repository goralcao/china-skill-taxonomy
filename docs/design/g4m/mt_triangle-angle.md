## 三、仿真 spec

**机制**：底边 A(110,270)、B(430,270) 固定，顶点 C 由案例给定；三个角的度数用向量点积反余弦实时算出，按 `step = 0~3` 逐个「撕下」并搬到右侧平角线上累积。

- 左侧三角形三个顶点各画一个半径 42 的内侧小扇形（`simWedge` 用 `atan2` 求两边夹角，自动处理顺/逆时针），已撕走的改虚线轮廓、度数变灰
- 右侧以 `O=(670,270)`、`R=112` 画平角：从 `θ=π` 起，每加一个角 `α` 画扇形 `[θ, θ+α]`，`θ += α`；三个加完 `θ = 2π`，正好从直线左端铺到右端（Canvas 角度 `[π,2π]` 是上半平面）
- 未撕的扇形画虚线轮廓，因此初始状态就能看到「半圆将被分成三份」
- 三色固定：`#26C6DA` ∠1 / `#FFA726` ∠2 / `#66BB6A` ∠3，左右一致
- `hide3` 案例把 ∠3 显示为 `?`，底部同步给出 `∠3 = 180° − ∠1 − ∠2 = …`，拼满后仍在状态栏隐藏
- 画布点击：命中任一顶点半径 48 → 直接撕到该步；点空白处 → `simNext()`

| 案例 | C 坐标 | ∠1 / ∠2 / ∠3 | 说明 |
| --- | --- | --- | --- |
| 风筝骨架 · 一般 | (230, 90) | 56° / 42° / 82° | 三角全显示 |
| 等腰锐角 | (270, 60) | 53° / 53° / 75° | 两底角相等 |
| 直角三角板 | (383, 157) | 22° / 67° / ? | 以 AB 为直径的圆上，∠3 = 90° |
| 红领巾 · 钝角 | (270, 245) | 9° / 9° / ? | ∠3 = 162°，顶点贴近底边时标在上方 |

直角案例用泰勒斯定理构造（圆心 (270,270)、半径 160）。函数：`simCase / simNext / simPrev / simReset / simDemo / simDraw / simLog / simBind`；`simNext` 拼满后再按会切下一案例。

## 四、易错点

1. **以为大三角形角更大**：放大只改边长，角的张口没变，内角和恒 180°。
2. **剪开就把 180° 分掉**：剪出的每一块仍是三角形，各有自己的三个角，各是 180°。
3. **两角相加当第三角**：65° + 45° = 110° 是已知两角之和，第三角要 180° − 110° = 70°。
4. **直角忘了先扣掉**：直角占 90°，两锐角合起来就是 90°，不用再拿 180° 减两次。

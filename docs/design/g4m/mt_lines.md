## 三、仿真 spec

**机制**：画布中央一条水平线，`L`（左端）与 `R`（右端）各有一个「是否已去掉端点」的开关。端点数 `n = 2 − L − R`，由 `n` 反推名字：

| L | R | n | 名称 | 长度标注 | 三项面板 |
| --- | --- | --- | --- | --- | --- |
| 0 | 0 | 2 | 线段 AB | 实线尺寸标 `8 厘米` | 2 / 能 / 不能 |
| 0 | 1 | 1 | 射线 | 虚线 + `量不出来` + `从端点出发，一直走不到头` | 1 / 不能 / 只能一头 |
| 1 | 0 | 1 | 射线 | 同上 | 1 / 不能 / 只能一头 |
| 1 | 1 | 0 | 直线 | 虚线 + `量不出来` + `两头都走不到头` | 0 / 不能 / 两头都行 |

**几何**：
- 画布 880 × 360，中线 `SIM_CX = 440`，主线 `SIM_Y = 152`，比例 `40px = 1 厘米`
- 线长由案例的 `len` 决定：`half = len × 40 / 2`，左右端 `440 ∓ half`
  - 8 厘米 → 280…600；6 厘米 → 320…560；12 厘米 → 200…680（延伸后 40…840，正好占满）
- 无限端画三段越来越淡的虚线（`[9,6] 1.0` → `[6,9] 0.6` → `[4,11] 0.3`）+ 末端实心三角箭头，「渐隐」比单纯一个箭头更能表达「一直延伸」
- 端点画成橙心白点的双层圆（`r = 9 / 3.4`），标注 A / B 在线上方 20px
- 三项面板 240 × 66 横排于 `y = 236`，`x = 60 / 320 / 580`

**交互**：
- `simLeft()` / `simRight()` 去掉对应端的端点；已去掉时日志提示「这一端已经没有端点了」
- `simBack()` 先恢复 R 再恢复 L（与去的时候反序）
- `simPick` 合并进画布点击：`y` 落在主线 ±36 内才响应，`x < 中线` 去左端点、否则去右端点
- `simCase(dir)` 换线（8 / 6 / 12 厘米），换题时 `L = R = 0`
- `simDemo()` 每 1000ms 推进一步：线段 → 去右端（射线）→ 去左端（直线）→ 停

函数：`simLeft / simRight / simBack / simCase / simReset / simDemo / simDraw / simRefresh / simLog / simBind / simName / simEnds / simTail / ctxArrow`。

## 四、易错点

1. **说直线比射线长**：两条都无限长，没有尽头，比不了。能比长短的只有线段。
2. **以为延长一次就成直线**：只延长一端得到射线，必须两端都延长才成直线。数端点数最稳：2 → 1 → 0。
3. **把「不相交」当平行**：必须补一句「同一平面内」。立交桥上下两条路永远碰不到，但它们是异面直线，不平行。
4. **把直线上两点之间那段叫直线**：那是线段，有 2 个端点、量得出长度。名字跟着端点数走。

## 五、验收

- 12 页零横向溢出，四组测验 14 题全对（pre `0,2,0` / mid1 `1,2,0` / mid2 `0,1,2` / post `2,0,2,1,1`）
- 连线 16 个元素，右列 8 个答案互不相同（90° / 射线 / 互相垂直 / 直线 / 只能画 1 条 / 无数条 / 互相平行 / 线段）
- 仿真：线段 → `simRight` 射线 → `simLeft` 直线 → `simBack` 回射线 → `simCase` 换 6 厘米 → `simReset` 回线段
- 画布着色像素 ≈ 316 700，V4 首卡 opacity = 1，控制台 0 错误
- 画布点击实测：点右半 → `R=1` 变射线；点左半 → `L=1` 变直线；点画布上方空白 → 无反应；换到 12 厘米后 `能量出 12 厘米`

# 位置与方向 · 逐页详细设计

- topicId：`mt_direction`　教材：人教版三下 u1　课时：40 分钟
- 配色：天空蓝 `#1565C0`（accent `#F9A825` 金黄）
- 认知动作：辨析（分清东南西北、左右与地图约定，辨清相对方向）
- 一句话：方向不随你转身变，变的是「你的左右」；地图永远上北下南左西右东

## 学情画像

| 项 | 内容 |
|---|---|
| 已有经验 | 知道太阳东升西落；会看简单示意图；认识前后左右 |
| 前概念（要暴露的） | ① 把「左手边」直接当西（没看面向）；② 地图上下搞反（以为上方是南）；③ 东西弄反（太阳从西边升起）；④ 相对方向说反（A 在 B 东边，以为 B 也在 A 东边） |
| 经验锚点 | 早晨上学看太阳 / 看地图找路 / 指南针 |
| 情感触发 | 「我明明没动，怎么方向变了」的较真 |

## 第 1 页 · cover

- 标题：**太阳从哪边升起？地图为什么上北下南？**
- 副标题：位置与方向 · 三年级数学
- 视觉：天蓝渐变 + 内联 SVG（指南针十字，北在上、东在右）
- tags：东南西北 / 上北下南 / 相对方向

## 第 2 页 · pre-test（3 题）

**Q1** 早晨太阳从哪个方向升起？
- A 东　B 西　C 北　→ **A**
- 解析：太阳东升西落。选西正好反了；选北不是日出方向。

**Q2** 地图上通常「上面」表示哪个方向？
- A 南　B 北　C 东　→ **B**
- 解析：地图约定上北下南。选南把上下弄反了。

**Q3** 面向北站立，你的右手边是哪个方向？
- A 东　B 西　C 南　→ **A**
- 解析：面向北，右手是东。选西是左右弄反；选南是背后。

## 第 3 页 · 引入（第一个 teach-title，承担 hook）

- 标题：**早晨 7:00，太阳从哪边升起？**
- 视觉：指南针 + 小人面向东
- 文案：7:00 太阳从东边升起；面向东，右手是南、左手是北；从家到学校走 8 分钟，先向东再向北
- 关键框：先定东，再按「东南西北」顺时针推

## 第 4 页 · 概念 1（四个方向 + 地图约定）

- 标题：**东南西北：先认东，再顺时针推**
- 逐段揭示：认东 / 顺时针 / 地图约定
- 表格：方向—地图位置—记忆
- 关键框：地图上「上北下南、左西右东」

## 第 5 页 · 连一连（matchP3）

| 说法 | 方向 |
|---|---|
| 太阳升起的方向 | 东 |
| 地图的上方 | 北 |
| 地图的左侧 | 西 |
| 面向北时右手边 | 东 |

## 第 6 页 · 中测 1（3 题）

- 地图下方=南；面向东左手=北；太阳落下=西

## 第 7 页 · 概念 2（用方向描述位置与路线）

- 标题：**用方向说清位置：先看参照，再说方向**
- 三张卡：说位置要有参照；路线按顺序说；相对方向相反
- 关键框：说方向前先定「站在哪、看哪里」

## 第 8 页 · 仿真（方格地图上按方向走）

- 交互：向东/南/西/北走一格、演示路线、重置
- 读数：从起点向东/北各几格，当前位置
- 观察问题：面向不同方向，左右怎么变？相对方向为什么相反？

## 第 9 页 · 中测 2（3 题）

- 相对方向；先北后东到东北；地图左上角=西北

## 第 10 页 · 易错辨析（4 卡）

- ① 左右当方向 ② 地图上下搞反 ③ 东西弄反 ④ 相对方向说反
- 迁移：学校东边 300 米是书店，书店西边就是学校

## 第 11 页 · 后测（5 题）

- 日出东；地图右=东；面向南左手=东；A 在 B 北则 B 在 A 南；东 2 北 1 的起点在西南

## 第 12 页 · 总结 V4

- 认东（日出）/ 顺时针（东南西北）/ 地图（上北下南左西右东）/ 说位置（先参照再方向）

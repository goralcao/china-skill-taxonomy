# 复式统计表 · 逐页详细设计

- topicId：`mt_stats-table`　教材：人教版三下 u3　课时：40 分钟
- 配色：靛蓝 `#3949AB`（accent `#00897B` 青绿）
- 认知动作：构造（把两组单式数据，构造进同一张表，共用一个表头）
- 一句话：复式统计表不是数字变多，是「横看一类、竖看另一类」，一眼能对照

## 学情画像

| 项 | 内容 |
|---|---|
| 已有经验 | 会看简单单式统计表；会分类计数；会求几个数的和 |
| 前概念（要暴露的） | ① 以为复式表就是数字更多；② 不会写左上角表头；③ 分不清横竖各表示什么；④ 不会用合计做比较 |
| 经验锚点 | 两个班零花钱 / 男女生人数 / 兴趣小组 |
| 情感触发 | 「两张表来回翻太麻烦，能不能合成一张」的较真 |

## 第 2 页 · pre-test（3 题）

**Q1** 要比较两个班各兴趣小组人数，用哪种表更方便？
- A 两张单式表　B 一张复式表　C 不用表　→ **B**
- 解析：复式表把两组放一起，方便对照。两张单式表要来回翻。

**Q2** 复式统计表左上角通常写什么？
- A 标题　B 说明横竖各表示什么　C 日期　→ **B**
- 解析：左上角是表头，说明横、竖各是什么。

**Q3** 三（1）班男生 20 人、女生 18 人，全班共几人？
- A 38　B 2　C 20　→ **A**
- 解析：20+18=38。选 2 是相减；选 20 漏了女生。

## 第 3 页 · 引入（第一个 teach-title，承担 hook）

- 标题：**三（1）班 120 元、三（2）班 110 元，怎么放进一张表？**
- 视觉：复式统计表（男/女 × 三1/三2 + 合计）
- 文案：男生三1 120 元、三2 110 元；女生三1 100 元、三2 130 元；四组数据合成一张表
- 关键框：复式表 = 两组数据放进同一张表，共用一个表头

## 第 6 页 · 中测 1（3 题）

- 复式表最大的不同；表头「班级」是横向类别；三1 男 120 女 100 合计 220

## 第 7 页 · 概念 2（看表分析）

- 标题：**会看表：横着比、竖着比、算合计**
- 三张卡：竖着比（同班男女）/ 横着比（同性别两班）/ 合计与总计
- 关键框：复式表的价值在「对照」

## 第 8 页 · 仿真（复式统计表 + 看表高亮）

- 交互：看男生行/女生行/三1列/三2列/看合计/重置
- 读数：高亮区域的数据与合计
- 观察问题：横看是什么、竖看是什么？合计怎么算出来？

## 第 9 页 · 中测 2（3 题）

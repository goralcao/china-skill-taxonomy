> Step 2 统一规范。每课另有一份 `<topicId>.md` 逐页设计。
> 本文定「怎么设计」，各课文件定「这一课具体是什么」。

## 1. 页面骨架（固定 11 页，内容多可扩到 14）

## 2. 文案规则

- 标题只说「要解决什么」，不写「第 X 课时」「本课学习目标」
- 正文第二人称、短句，每段 ≤3 行
- 每页至少 1 个具体数字或具体物，禁止「同学们」「我们一起来」
- 引入页现象篇幅 ≤ 全页 30%，随即进入知识
- 讲授页不超过 3 行纯文字而无图（图走内联 SVG）

## 3. 测验规则

- 题型只有单选 / 多选，连线与分类只用于讲授页巩固
- 前测四要素：已有经验 / 暴露前概念 / 关联本课新知 / 情境喜闻乐见
- 同一测验内正确项位置必须打散（跑 `quiz-answer-check.js` 须 PASS）
- 后测至少 1 道迁移题：「用今天学的解释你身边的 ___」
- 每题必配 `explain`，说清「为什么错的那个选项会有人选」

## 4. 仿真 spec 模板

```
Name:        一句话说清这是什么
Goal:        学生脑子里的哪个错念头
Mechanism:   学生怎么操作，系统怎么响应
Parameters:  可调的量与范围
Visual:      画面上出现什么（表盘/格阵/数轴/地图）
Feedback:    操作后什么变了（颜色/数字/提示）
Boundaries:  边界与异常
Expected:    学生应该发现什么
```

## 5. 16 课题目规划（每课 14 题：前测 3 + 中测 3×2 + 后测 5）

| 课 | 前测考什么经验 | 中测 1 | 中测 2 | 后测迁移题情境 |
|---|---|---|---|---|
| 时分秒 | 起床到校的时间差、动画片时长、跑 50 米 | 钟面认读、针速 | 单位换算 | 煮鸡蛋计时 |
| 万以内加减 | 找零、攒钱差额、两位数退位 | 退位判断 | 估算与验算 | 义卖找零 |
| 吨的认识 | 体重、书包重量、电梯人数 | 吨与千克换算 | 估重 | 货车载重 |
| 倍的认识 | 「多几个」与「几倍」的日常说法 | 倍的意义 | 求几倍/求几倍量 | 跳绳比赛 |
| 多位数乘一位数 | 一箱几个、几箱一共 | 竖式顺序 | 末尾 0 与进位 | 运动会买水 |
| 周长 | 绕操场一圈、围花边用料 | 周长含义 | 长方形周长算法 | 相框木条 |
| 分数初步 | 分披萨、折纸平分 | 几分之一 | 比大小 | 分蛋糕 |
| 同分母加减 | 吃了几个、还剩几个 | 分数单位 | 加减算法 | 分西瓜 |
| 位置与方向 | 上下左右、地图认路 | 八个方向 | 路线描述 | 校园导览 |
| 除法 | 分糖、平均分 | 竖式与余数 | 余数与除数关系 | 班级分组 |
| 复式统计表 | 看单式表读数 | 表头与栏目 | 合并两表 | 兴趣班选课 |
| 面积单位 | 封面大小、地砖 | 面积含义 | 单位选择 | 贴墙纸 |
| 长方形面积 | 铺格子 | 公式由来 | 正方形特例 | 铺地砖 |
| 年月日 | 生日、假期天数 | 大月小月 | 24 时计时 | 火车票时间 |
| 小数初步 | 价签 3.5 元 | 小数含义 | 元角分 | 超市比价 |
| 小数加减 | 算总价 | 小数点对齐 | 进位退位 | 扫码结账 |

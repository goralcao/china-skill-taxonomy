# 一位小数加减法：小数点对齐再算 · 逐页设计

> 主色 藏蓝 `#1A237E` + 琥珀 `#FFA000`

## 0. 学情与立意

上一课刚把 0.1 变成看得见的一格，这一课要让它动起来。学生常见的三个错念头：

1. **末位对齐**：整数加减养成「右边对齐」的习惯，搬到小数就变成 0.3 的 3 和 0.25 的 5 对齐。
2. **算完忘了点小数点**：0.7 + 0.6 算成 13，写答案时直接写 13。
3. **减法反着减**：1.2 − 0.5，个位 2 减 5 不够，就把 5 − 2 = 3，写成 0.3。

本课用一句话把它们一次解决（认知动作「变换」）：**先把每个数都换成「几个 0.1」，再像整数一样加减，最后换回小数**。0.3 是 3 个 0.1，1.2 是 12 个 0.1——变换完，加减就是整数加减。

## 3. 仿真 spec

```
Name:        两条小数条 + 竖式——加减到底在加什么
Goal:        打掉「末位对齐」与「算完忘点小数点」两个错念头
Mechanism:   画布左侧两条十格条显示 A、B 的十分位格数；右侧是小数点严格对齐的竖式。
             点「0.3+0.4 / 0.7+0.6 / 0.9−0.4 / 1.2−0.5」四个预设直接对比，
             「B +0.1 / B −0.1」自己调，切换 + 与 − 看结果怎么变
Parameters:  A = 0.a（或 1.a），B = 0.b；a、b 各 0…9
Visual:      三行：A 条、B 条、结果条；右侧竖式的三个数字位（整数 / 小数点 / 十分位）固定列位
Feedback:    读数条写「0.3 + 0.4 = 0.7（3 个 0.1 + 4 个 0.1 = 7 个 0.1）」，进位时写「满十进一」
Boundaries:  减法时 A 必须不小于 B，否则提示「小数减大数，三年级还不算」
Expected:    学生发现竖式里小数点排成一条竖线，就是「数位对齐」；
             并且 0.7+0.6 的 13 要写成 1.3，不是 13
```

## 4. 易错页（p8）四张卡

| # | 错版 | 正解 |
|---|---|---|
| ① | 末位对齐：0.3 的 3 对着 0.25 的 5 | 小数点对齐，十分位对十分位，百分位空着补 0 |
| ② | 0.7 + 0.6 = 13 | 13 个 0.1 = 1.3，小数点不能丢 |
| ③ | 1.2 − 0.5 算成 0.3 | 2 − 5 不够减，向前一位借 1 当 10：12 − 5 = 7，得 0.7 |
| ④ | 0.3 + 0.4 = 0.70 | 一位小数结果还是一位：0.7 |

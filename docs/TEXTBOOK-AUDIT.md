# 2024 版教材对齐核查报告

> 核查对象：`data/topics.json` 的 `textbooks2024`（知识点 → 2024 新版教材单元）
> 核查基准：国家中小学智慧教育平台的 **2024 新版**教材预览页
> 核查日期：2026-11-03
> 核查范围：17 册（数学 7、语文 7、英语 3），覆盖 133 个 `textbooks2024` 对齐条目

## 结论先行

**`textbooks2024` 的 2024 版对齐质量很高，不需要大规模修改。**

- 成功取到新版目录并完成核对：**17 册全部**（数学 7、语文 7、英语 3）
- `data/textbooks.json` 的 `units` 顺序与真教材目录**逐条一致**（数学 7 册、英语 3 册全部通过）
- 绝大多数 `uN` 指向正确；**仅 7 处**因「2024 新版删除了该独立单元」而失准（见第 5 节）

这一结论与 2026-09 那次「误判后回滚」的结果一致，但本次是**对着真教材目录核出来的**，不是推测。

## 1. 关键方法突破：两个 preview 不是同一份

上一轮（2026-09）曾错误地认为「国家平台匿名链路只有 2012 旧版」，据此把 16 处对齐**改错**，随后回滚。本次查明真相：

| 取法 | 实际内容 | 时间戳 |
|---|---|---|
| `details/{contentId}.json` → `custom_properties.preview` | **2022 旧版**（2012 课标） | `.../1664445558xxx/`（2022-09） |
| **匿名索引条目** → `custom_properties.preview` | **2026 新版**（2024 课标修订） | `.../1787023027xxx/`（2026-08） |

同一个 `contentId`（如人教数学四上 `654e3d1e…`），两条路径给出的预览页**内容完全不同**：

- 走 detail：目录是「大数的认识 / 公顷和平方千米 / 三位数乘两位数」，2012 旧版
- 走索引：目录是「万以上数的认识 / 1亿有多大 / 多位数乘两位数」，**2026 秋新版**

判定版本的可靠依据是 preview URL 里的 **13 位毫秒时间戳**，而不是 `create_time`（批量导入值，普遍是 2022-09-29）或 `update_time`（索引扫描时间）。

`scripts/audit-2024-new.py` 因此硬编码了「时间戳 < 2024-01-01 直接拒绝核对」的闸门。

## 2. `uN` 的真实语义（上一轮也搞错了）

`textbooks2024` 的 `uN` **不是 `units` 数组下标**，而是**过滤掉非教学单元后的序号**：

```
units 数组 = [activity 数学游戏, unit 5以内数, unit 6～10, unit 立体图形, ...]
                ↓ 剔除 type != "unit"
uN 序列    = [1 5以内数, 2 6～10, 3 立体图形, ...]
```

被剔除的类型：

| type | 例子 | 是否占 uN |
|---|---|---|
| `unit` | 5以内数的认识和加、减法 | 占 |
| `activity` | 数学游戏、曹冲称象的故事、时间在哪里、1亿有多大、寻找宝藏 | 不占 |
| `intro` | 我上学了（语文一上） | 不占 |
| `enrichment` | 数学广角：搭配问题 | 不占 |

**反推验证**（四点独立成立）：

| 知识点 | 当前 uN | 按数组下标 | 按正式单元序号 |
|---|---|---|---|
| 4a 角的度量 | u2 | 1亿有多大（activity）✗ | **角的度量 ✓** |
| 3a 多位数乘一位数 | u4 | 曹冲称象（activity）✗ | **多位数乘一位数 ✓** |
| 2b 有余数的除法 | u1 | 时间在哪里（activity）✗ | **有余数的除法 ✓** |
| 1a 立体图形的认识 | u3 | 6～10的认识 ✗ | **认识立体图形 ✓** |

上一轮按数组下标索引，得出「16 处错」，全部是索引方式造成的假象。

## 3. 基准可信度：textbooks.json 与真教材逐条一致

`data/textbooks.json` 的 2024 `units` 源自电子课本网（dzkbw 2026 秋版）。本次用 OCR 出的真实目录校验：

| 册 | 目录页 | units 数 | 目录中命中 | 顺序一致 |
|---|---|---|---|---|
| math 1a | p5 | 7 | 7/7 | ✓ |
| math 1b | p5 | 8 | 8/8 | ✓ |
| math 2a | p5 | 8 | 7/8 | ✓ |
| math 2b | p5 | 7 | 7/7 | ✓ |
| math 3a | p5 | 10 | 9/10 | ✓ |
| math 3b | p5 | 8 | 8/8 | ✓ |
| math 4a | p5 | 9 | 9/9 | ✓ |
| english 3a | p5 | 7 | 5/7 | ✓ |
| english 3b | p5 | 7 | 7/7 | ✓ |

未命中的项均为「目录外的补充内容」（如 3a 的 u10 数学广角：搭配问题）或**印次改名**（见下）。

**唯一发现的名称差异**：英语三上 u3，`textbooks.json` 写 `Amazing animals`，2026 秋印次目录印的是 `Our animal friends`。
属教材跨年印次的措辞调整，**单元序号不变**，不影响 uN，故未改动；若追求与最新印次字面一致，可单独更新该 name。

## 5. 七处失准点（均为教材改版导致，未自动修改）

这些知识点指向的单元，在 2024 新版里**已不作为独立单元存在**，属于内容重编而非编号笔误。在未确认新归属前**不擅自改号**：

| 知识点 | 现指向 | 实际单元 | 说明 |
|---|---|---|---|
| `mt_position-basic` 位置 | 1a:u1 | 5以内数的认识和加、减法 | 新版无独立「位置」单元；该点另有 `1a#数学游戏` 条目，位置内容应在数学游戏 activity 中 |
| `mt_pattern` 找规律 | 1b:u3 | 100以内数的认识 | 新版低年级无「找规律」独立单元 |
| `mt_pattern` 找规律 | 2a:u2 | 1~6的表内乘法 | 同上 |
| `mt_multiple` 倍的认识 | 3a:u4 | 多位数乘一位数 | 3a 无「倍」单元；该点已有 `2b:u2 数量间的乘除关系`（正确） |
| `mt_chicken-rabbit` 鸡兔同笼 | 4a:u7 | 复习与关联 | 新版四上无「数学广角—优化」；鸡兔同笼疑并入 u8「寻找宝藏」activity（不占 uN） |
| `mt_num-100-addsub` 100以内加减法（口算） | 1b:u3 + u4 | u3 是 100以内数的认识 | u3 冗余，应只保留 u4（100以内的口算加、减法） |
| `mt_stats-table` 复式统计表 | 3b:u5 | 数据的收集与整理 | 新版 3b 无「复式统计表」独立单元，内容并入「数据的收集与整理」 |

**建议**：这 7 处可改为「在 `textbookNote2024` 中说明 + 保留/删除指向」，而不是改成另一个具体单元号。是否处理待定。

## 7. 教训清单

1. **先定版本，再核对**。`create_time` 是批量导入值，不可信；认 preview URL 的 13 位时间戳。
2. **detail 与索引的 preview 可能不是同一份文件**。核新教材必须走索引条目。
3. **`uN` 不是数组下标**，要过滤 `activity`/`intro`/`enrichment`。
4. **改数据前先用「已知正确的点」反推索引方式**——本次若没做这步反推，会第三次改错。

# 2024 版教材对齐核查记录（含一次误判的复盘）

> 目的：核对 `data/topics.json` 的 `textbooks2024`（知识点 → 2024 新版教材单元）是否与真实教材一致。
> 结论先行：**`textbooks2024` 的 2024 结构以 `data/textbooks.json`（源自电子课本网 dzkbw 的 2026 秋版）为准，经外部多源核实是正确的，本次无需修改。**
> 中间曾误把国家平台的**旧版**目录当成新版、误改过 16 处，已全部回滚——这段教训见第 3 节。

## 1. 核查方法（全程匿名，无需登录）

国家中小学智慧教育平台有一条匿名可读链路：

1. 匿名整库索引 `…/tch_material/version/data_version.json`
2. 详情 `…/tch_material/details/{contentId}.json`
3. 详情里 `custom_properties.preview` 的 `Slide1..N` 是整页 JPG，匿名可下
4. 对预览页做 OCR 行还原 → 命中「目录」的即目录页 → 解析单元/课节

OCR 用 `scripts/ocr_lines.py`：PP-OCRv4 模型经 **RapidOCR（onnxruntime）** 推理。
本机 paddlepaddle 2.6.2 在 Xeon 6981E 上于 oneDNN 图融合 pass 抛 `SIGILL`，故走同模型的 RapidOCR。

## 2. 关键事实：匿名链路拿到的是「旧版」教材

- 人教版数学四上 `contentId=654e3d1e…`：`create_time=2022-09-29`（2022 年上传），预览页目录为
  **「大数的认识 / 公顷和平方千米 / 角的度量 / 三位数乘两位数 / 平行四边形和梯形 / 除数是两位数的除法 / 条形统计图 / 数学广角—优化 / 总复习」**——这是 **2012 课标旧版**。
- 而 **2024 新人教版四上**真实目录是
  **「万以上数的认识 / 1亿有多大 / 角的度量 / 多位数乘两位数 / 加法模型和乘法模型 / 平行四边形和梯形 / 条形统计图 / 寻找宝藏 / 复习与关联」**。
  该结论由多源交叉核实一致：电子教材网 sjds.net、ChinaTextBook 的 2024 版 PDF 目录截图、教习网 51jiaoxi、21世纪教育网 21cnjy。

也就是说：国家平台这条匿名索引里的预览页普遍是 **2012 课标旧版**，**不能用来核对 2024 新版对齐**。

## 3. 一次误判的复盘（重要）

初次跑 `scripts/audit-textbook-align.py` 时，未核对版本年份，把上述**旧版**目录当成了新版，得到「数学 7 册 62 点中 16 点单元号不符」，并据此修改了 `topics.json`（commit `795bc67`）。

事后用 `create_time` 与外部权威目录比对，确认这批「不符」全部来自旧版输入，属于**把对的改错**。随即：

- `git reset` 撤销该 commit，`topics.json` 恢复到原始（校验：dict 结构、`version=v0.49.0`、1273 个知识点、无改动）。
- 删除会批量改数据的 `scripts/apply-audit-fixes.py`。
- 在 `scripts/audit-textbook-align.py` 顶部写入旧版局限说明，`find_book` 命中 2024 年前创建的条目时打印醒目告警。

**教训：核对教材对齐前，必须先确认拿到的目录是「哪一版」——用 `create_time`、标题年份、或与权威目录互证，不能只看「人教版 + 年级 + 册次」就下结论。**

## 4. 语文 / 英语 的核对情况

- 同样受「匿名预览为旧版」限制，`audit-textbook-align.py` 抓到的是语文/英语旧版目录。
- 语文一上旧版目录（我上学了 / 识字·天地人 / 汉语拼音 / 课文·秋天 …）与 2024 版一上结构**恰好高度一致**（语文低年级改动小），但这只是巧合，不能据此断言 2024 版已核。
- 英语 2024 版单元主题与旧版「差异很大」（见 `textbooks.json` 的 note），旧版目录更不能代表新版。
- 因此**未对语文/英语做任何数据修改**；`textbooks2024` 维持 `textbooks.json`（dzkbw 2026 秋版）的映射不动。

## 5. 若要真正核对 2024 新版，建议的途径

- **首选**：`data/textbooks.json` 的 2024 `books[].units` 已逐单元记录 name/type/page/lessons（源自 dzkbw 2026 秋版，已与多源互证），直接以它为权威即可，无需再 OCR。
- 需要独立复核时：取 **2024 新版教材的 PDF/预览**（而非国家平台匿名旧版），再套用 `ocr_lines.py` 做目录行还原比对。
- `uN` 语义：`textbooks2024` 的 `uN` = 「正式教学单元序号」——须先过滤 `type=intro`（如语文「我上学了」）后取第 uN 个，否则会整体错位一位（本次曾因此误判语文一上 7 条）。

## 6. 工具清单

| 文件 | 用途 | 备注 |
|---|---|---|
| `scripts/ocr_lines.py` | 教材目录页 OCR 行还原（PP-OCRv4 / RapidOCR） | 通用，可复用 |
| `scripts/audit-textbook-align.py` | 从国家平台抓某册目录并可选比对 | 顶部有旧版局限说明；仅适用于旧版目录提取 |

> 权利边界：仅记录「存在哪一册、第几单元、单元名/课节名」这类结构信息，不复制教材正文。

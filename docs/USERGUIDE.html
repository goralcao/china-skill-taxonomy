先看懂三种图形

硬依赖：不会它就学不了这个（必须先补）；软依赖：学了有帮助、不学也能往下走。圆点的大小代表「枢纽程度」——越大的点被越多后续知识依赖，值得优先补牢。

03三种布局

工具栏「布局」一栏可随时切换，网址里也会记住当前布局。

布局怎么读适合什么时候用
星图（默认）学科围圈、簇在圈内，纵轴 = 年级（上小下大）看全局结构、看依赖关系、追「这个知识从哪来、通向哪」。
长卷横轴 = 册次（1 年级上 → 12 年级下，共 24 列），纵轴 = 学科泳道手边有教材、想按「第几册第几单元」对照进度时最直观。
热力行 = 学科、列 = 年级的密度矩阵，颜色越深知识点越密集快速判断「哪个学段内容最重」，点击格子会跳回长卷并定位到该学科该年级。

04找知识点：搜索与筛选

搜索框（推荐）

按 / 或直接点击搜索框，输入主题名（如「分数」「圆」）或领域名。结果以下拉列表出现，最多显示 40 条，排序规则是：完全同名 → 名称开头匹配 → 低年级优先。

  • 列表内 ↑ ↓ 选择、Enter 打开、Esc 关闭；也可以直接鼠标点选。
  • 选中的主题若被当前筛选/折叠藏着，图谱会自动放宽条件（点亮所属学科、清掉冲突的年级/领域筛选）再聚焦，不会「点了没反应」。

四个筛选器

筛选器行为
学科圆点 × 12多选开关，点亮的学科才显示；可以只留一个（如只看数学）。
▶ 有课件只显示配了互动课件的知识点（当前 65 个），显示为自适应网格。
年级下拉只显示覆盖该年级的主题（一个主题可能跨年级，如「圆的认识」6~6 年级）。
领域下拉按学科分组的领域（如「数与代数」「图形与几何」）；选中后自动点亮相关学科。
筛选命中的领域簇会自动展开，不会出现「筛了但图上是空的」。想全图重来，点「⋯ → 重置视图」；只想清某个筛选，把下拉选回「全部」即可。

05图上的操作

动作效果
悬停任意节点点亮它和它的先修/解锁邻居，其余淡出——最适合顺着连线「看这条路怎么走」。悬停簇环高亮簇内全部，悬停学科环高亮整个学科。
点击知识点打开右侧详情面板（诊断、路径、教材、研究全在这）。
点击学科环 / 簇环折叠 ↔ 展开这一层。移动端打开时默认折叠，逐层点开即可。
拖动知识点把它的位置固定下来（提示「已固定」），方便整理自己顺眼的布局；点「重置视图」解除全部固定。
拖动空白处平移画布，松手带一点惯性滑动。
滚轮 / 双击 / 双指捏合缩放（双击放大 1.6 倍，缩放以指针/双指中心为锚点）。

「⋯ 更多」菜单里的两个高能按钮

  • 追溯全部先修：选中一个知识点后点它，图上会高亮整条上游链（所有前置，含前置的前置）。回答「要学会它，总共得会多少东西」。
  • 查看后续解锁：反过来高亮整条下游链。回答「学会它能打开哪些新知识」，适合判断一个基础点值不值得花力气。

其余三项：显示全部名称（切换所有节点的文字标签，默认只显示放得下的）、未标记掌握 → 隐藏已掌握（只看待学，见 08）、重置视图（清选中、解除固定、回到全图鸟瞰；不清除学科/年级筛选）。

06详情面板：一个知识点的完整档案

点击任意知识点后，面板从上到下依次是：

区块怎么用
标题行名称 + 学科徽标 + 领域 + 年级范围 + 学段；若有课件会标注「课件 N 分钟 · 已完成」。
三个动作按钮▶ 打开课件（有课件才出现）/ ✅ 标记已掌握 / 🗺️ 生成学习路径。
掌握诊断通往这个知识点总共 N 步：已会几步、待补几步、进度条，以及「下一步最该学」（最多 6 个，可点击直达）。这是给「孩子卡住了」场景的核心答案。
学什么一句话描述这个知识点。
掌握证据能做到这些才算会——一组可观察的行为（「能说出…」「能用线段图表示…」），比「懂了没」可检验得多。
家长检查法一句可以直接照着问的检查问题。
课标对齐对应的义务教育/高中课标条目编号与摘要。
教材位置该知识点在各版本教材的册次与单元，多数可点击直达官方页；还有「📖 教材版本对照」（见 10）。
教学研究1268 篇研究对应到每个主题：怎么引入、常见错误、教学建议等。
先修 / 解锁上下游列表，点击可跳转；每条会标注硬依赖 / 软依赖。
点击学科环或簇环打开的是容器面板：该范围的统计、知识点清单，以及「整组标记已掌握」——开学初或学期末批量核对进度时很好用。

07学习路径：把「补课顺序」排出来

在详情面板点 🗺️ 生成学习路径，图谱会把这个知识点的全部先修做拓扑排序——先修永远排在目标前面，并按学段自动分阶段：

第 1 阶段 · 1~2 年级
1. 平面图形的认识（已会）
2. 线段、射线、直线与相交平行（已会）
第 2 阶段 · 4 年级
3. 三角形的分类
第 3 阶段 · 6 年级
4. 圆的认识（目标）
  • 仅硬依赖（默认）：最短必需路径，一步不多；含软依赖：把「有帮助」的辅助主题也排进来，时间充裕时用。
  • 已标记掌握的步骤自动划掉；点击任意一步可跳到那个知识点。
  • 导出 Markdown：下载一份带勾选框的清单（含每步「学什么 / 怎么教 / 课标 / 教材位置」），适合打印贴墙上或发给老师。
  • 打印：打印版自动转白底，只输出路径清单。
路径只基于图谱数据排序，「先修齐了」不等于「一定能学会」——结合详情面板里的掌握证据和教学研究判断孩子的真实起点。

08掌握进度与前置诊断

先标：手动记「这个会了」

  • 标记：详情面板「✅ 标记已掌握」，或选中后按 m。标记过的知识点带金色外环。
  • 批量：点学科环/簇环打开容器面板整组标记；容器再点一次可整组取消。
  • 专注待学：「⋯ → 未标记掌握」按钮会变成「隐藏已掌握 N」，把学过的暂时从图上拿掉。
  • 进度：顶栏进度条按学科实时更新，点击进度条上的学科可开关筛选。
  • 清空：「⋯ → 清空标记」（有确认弹窗）。所有标记只存在本机浏览器里（见 14 · 数据与隐私）。

标记的作用是算「通往目标 N 步里已会几步、下一步最该学什么」。但这是你说了算，不是题说了算。

再测：让题说了算

选中一个知识点，点面板上的「🧪 测一测」，系统按这个点出几道题。工具栏的「◎ 可测 50」可以先筛出哪些点有题。

  • 答错不立刻判不会。先就这个点再出一道更基础的确认题：确认题对了记「不稳」——会，但不牢，不往回追；确认题也错才判「薄弱」，这时才沿先修边往回追。
    一次对一次错更像粗心；两次都错才足以说明这个点没建立。错一道就把孩子拖回去重学，他会厌。
  • 每道题都说清为什么现在问它：是你选的目标本身，还是「某某没过，往回查它依赖的这一步」，还是同一个点第二次问。
  • 一个点要连续答对两道才算掌握。只答对一道可能只是蒙对。
  • 答错时摊开三件事：正确答案、你选的那一项为什么错、这个点该记住什么。
  • 结果页给根因：追到「它的先修里没有别的薄弱点」为止，然后按年级从低到高排补课顺序，每个点旁边直接给「上这一课」。
诊断进度存在本机浏览器（键名 stx.diag.v1），刷新不丢，只保留最近一轮、只对同一个目标生效；做完自动清掉。
题库目前覆盖 50 个知识点（都做过课件），占全图 3.9%。其余的点没有题——点开会明说「这个点还没有诊断题」，并列出相邻的可测点。不做假按钮：能测才给测，不能测就说清为什么。

09课件：能动手学的 65 个知识点

图谱回答「学什么、先学什么」，课件回答「学生自己怎么学」。目前覆盖 65 个知识点（以小学数学为主，含语文、物理、化学），每个都是约 10~15 分钟的互动课件。

  1. 工具栏点「▶ 有课件」，或在详情面板看到「课件 N 分钟」标注。
  2. 点「▶ 打开课件（N 分钟）」，新页面打开单文件课件：情境引入 → 分步交互 → 随堂检测。
  3. 做完后点完成，自动返回图谱并弹出成绩提示（答对 X 题 · 用时 Y 分钟）。
  4. 完成状态回写图谱：按钮变成「再看一遍」，元信息显示「已完成」，并参与掌握诊断的「已会」统计。
课件的完成记录同样只存本机浏览器（键名 stx.course.主题id），换设备不同步。

10教材位置与版本对照

详情面板的「教材位置」标出知识点在现役教材中的册次与单元（如人教版数学三(上) 第 5 单元），多数条目可以点击直达出版社官方页面。

点「📖 教材版本对照」会弹出一个并排对照卡：现役教材 vs 2024 年版课标修订教材，高亮该知识点在两个版本里各落在哪个单元，并附修订说明（例如某内容移年级、改表述）。部分学科另有北师大版、苏教版、外研社版分组展示。

2024 版修订教材按年级滚动出版，尚未覆盖的册次会注明「暂沿用现役版本」，不代表内容没变。

11分享链接：把状态写进网址

任何筛选、布局、选中的主题都会在约 0.3 秒后自动写入地址栏。复制地址栏发给任何人，对方打开就是你看到的这个画面（含选中的知识点并自动聚焦）。

参数含义示例
t选中的主题 id#t=mt_circle（圆的认识）
s点亮的学科（+ 连接）#s=数学+物理
g年级筛选#g=5
d领域筛选#d=图形与几何
c仅看有课件#c=1
l布局：star / scroll / heat#l=scroll

参数可自由组合，例如「只看数学长卷、定位到圆的认识」：
#t=mt_circle&s=数学&l=scroll

全默认状态下网址不带参数，不会污染地址栏；从课件返回时 URL 里的 ?done=1&score=…&minutes=… 只用来弹一次成绩提示，随后自动清掉。

13手机与平板

  • 打开即折叠：窄屏下默认只显示「学科环 + 领域簇」两层，避免一次糊上千个点；点学科环 → 点簇环逐层展开。
  • 触摸手势：单指拖空白 = 平移；按住知识点拖 = 固定位置；双指捏合 = 缩放。触摸的命中范围比鼠标大（约 24px），手指粗也能点中。
  • 搜索：结果列表全宽固定在搜索框正下方，点选直达。
  • 工具栏：学科圆点一行横向滑动；「有课件」筛选在窄屏下按年级分组自适应排布，不会挤成一团。
  • 详情面板：从底部铺开占满全屏，Esc 或右上角 × 关闭。

14数据与隐私

  • 无账号、无上传、无追踪：所有计算在你的浏览器里完成。
  • 你的数据只存本机 localStorage，共三处：cst-mastered-v1（掌握标记）、stx.course.主题id（课件完成记录）、stx.legend.open（图例开合）。
  • 清除浏览器数据 / 无痕模式会丢掉标记；想留底，可用学习路径的「导出 Markdown」（里面带每步的勾选状态）。
  • 数据开放在 ODbL 1.0（数据）与 CC BY-SA 4.0（内容）下，JSON + JSON Schema 可直接被程序读取。

15常见问题

首次打开会不会很慢？
v0.42 起首屏只加载 741KB（此前 4.2MB），常用网络下 1 秒左右出图。详情长文本、教学研究等在你点开节点时才按需加载——弱网下详情区可能先显示「加载中…」，稍等片刻即到；首屏画稳后图谱会趁空闲预取详情，通常点开时已经就绪。
筛选后图上什么都没有？
按顺序检查：① 学科圆点是否全被划掉（划掉的有删除线）；② 年级/领域下拉是否选了与学科冲突的值；③ 是否开着「隐藏已掌握」。最快办法：搜索一个主题名回车——图谱会自动放宽冲突筛选。
搜不到某个知识点？
图谱按微知识点粒度拆分（1273 个），名称可能与你习惯的说法不同，如「凑十法」拆在「20 以内进位加法」里。换更笼统的词（如「进位」「分数」）再试，或用领域下拉浏览。
换台电脑，掌握标记全没了？
标记只存本机浏览器。暂无云端同步；迁移可用「导出 Markdown」带走路径与勾选状态，或等后续版本的导入导出功能。
不小心拖乱了节点位置？
「⋯ → 重置视图」一键回到全图鸟瞰，同时解除所有固定。它不会清掉你的学科/年级筛选。
能离线用吗？
能。把整个 viz 目录下载后直接双击 index.html 即可（按需数据用脚本方式加载，file:// 打开也兼容）；课件同样是单文件、零外部依赖。
学习路径可信吗？
排序依据是图谱中人工整理并逐条标注理由的先修关系（硬 952 / 软 695），对齐 2022 年版课标。它回答「先后顺序」，不替代对孩子当前水平的判断——结合掌握证据与「家长检查法」使用。

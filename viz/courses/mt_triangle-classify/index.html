A1 个
B2 个
C3 个

单选题3. 等边三角形按边分是「等边」，按角分呢？

A锐角三角形
B直角三角形
C钝角三角形

3 个角、3 条边，一个三角形为什么能有两个名字？

校门口新立的警示牌，三条边都是 40 厘米，师傅叫它「等边三角形」；旁边车棚顶那个，师傅却叫它「钝角三角形」。

前一句在数边，后一句在看角。同一块三角形板，换个标准就换个名字。

所以一个三角形往往能同时领两张标签：一张按角，一张按边。两张都要说，才算介绍完整。

按角看

锐角 / 直角 / 钝角

只盯最大的那个角，三选一。

按边看

不等边 / 等腰 / 等边

数一数有几条边一样长，三选一。

两张合起来

等腰直角三角形

前半句说边，后半句说角。

分类不是「二选一」，而是两个维度各选一个。问清楚「按什么分」，才答得准。

按角分：只看最大的那个角

三个角都小于 90°，是锐角三角形；有一个角正好 90°，是直角三角形；有一个角大于 90°，是钝角三角形。

判断时只要看最大的那个角：它没到 90°，另外两个更不可能到，三个就全是锐角。

  • ① 最多一个直角或钝角：两个直角就 180° 了，第三个角没地方放。
  • ② 看最大角就够：最大角 < 90° 全锐，= 90° 直角，> 90° 钝角。
  • ③ 别被形状骗了：很扁的三角形不一定钝，很尖的也不一定锐，量最大角才算数。
按角分只问一句：最大的角比 90° 大、小，还是正好相等？

连一连：该给这块三角形贴哪张标签

左边是特征或名字，右边是唯一对应的标签。点左边一项，再点右边一项。

中测 1 · 按角分

三题都在考：最大的那个角说了算。

单选题1. 一个三角形最大的角是 88°，它是哪一类？

A锐角三角形
B直角三角形
C钝角三角形

单选题2. 三角形里有一个角是 90°，另外两个角？

A都是锐角
B一个直角一个锐角
C都是钝角

单选题3. 一个三角形有两个角是 45°，按角分是？

A锐角三角形
B直角三角形
C钝角三角形

按边分：数一数有几条边一样长

三条边都不相等，叫不等边三角形；有两条相等，叫等腰三角形；三条都相等，叫等边三角形。

等边三角形三条边两两相等，当然也满足「有两条相等」。所以等边是等腰里最特殊的一种。

  • ① 等腰看「至少两条」：等边三角形也算等腰，别把它排除在外。
  • ② 等边一定三个角都是 60°：按角分它永远是锐角三角形。
  • ③ 复合名字：「等腰直角三角形」＝按边等腰 + 按角直角，两张标签各管一头。
按角、按边是两条独立的轴。等腰可以是锐角、直角，也可以是钝角；等边只能是锐角。

拖一拖顶点，两张标签跟着变

底边 A、B 固定，橙色手柄是顶点 C。拖它或点画布任意位置，三个角、三条边和两张分类标签会一起重算。

按角：锐角三角形｜按边：不等边三角形 最大角 61°

橙色圆点是顶点 C，按住拖动；右侧六个标签里亮起来的就是它此刻的名字

  • 把顶点拖到正中间很高处，按边分变成什么？
  • 顶点压到接近底边时，按角分为什么变成钝角？
  • 能不能拖出「等边钝角三角形」？为什么？
  • 等腰直角三角形要同时满足哪两件事？

中测 2 · 按边分与两张标签

三题都在考：别把两条轴搅在一起。

单选题1. 有两条边相等的三角形叫什么？

A等边三角形
B等腰三角形
C不等边三角形

单选题2. 等边三角形一定是等腰三角形吗？

A是，它是最特殊的等腰
B不是，两者完全分开
C要看角度才知道

单选题3. 「等腰直角三角形」，按边和按角分别属于？

A等边 + 锐角
B等腰 + 直角
C不等边 + 钝角

四个坑，第三个最绕

① 看到大角就叫钝角

✗ 有个角 88°，是钝角

钝角要严格大于 90°。88° 还差 2°，最大角没过线就仍是锐角三角形。

② 把等边排除出等腰

✗ 等边不是等腰

「有两条边相等」等边也满足，而且满足三次。等边是等腰的特例。

③ 以为等腰一定锐角

✗ 等腰三角形都是锐角

等腰只管边。顶点压低就是钝角等腰，抬到特定高度就是等腰直角。

④ 只报一张标签

✗ 它是直角三角形，完了

按角说完了，按边还没说。完整说法要两张：不等边直角三角形。

说名字前先问两句：按角，最大角过没过 90°？按边，有几条边一样长？

回到桥架：有一格钢架最大角 120°、两条斜杆一样长，按角是钝角三角形，按边是等腰三角形，合起来叫「等腰钝角三角形」；另一格三根杆都等长、三角都是 60°，就是「等边锐角三角形」。

这一课，装进四张卡

1
按角
锐角 / 直角 / 钝角
▼
只看最大角点击翻面
最大角 < 90°：锐角
= 90°：直角
> 90°：钝角，最多只有一个
2
按边
不等边 / 等腰 / 等边
▼
数相等的边点击翻面
0 组相等：不等边
至少 1 组：等腰
3 组全等：等边（特殊等腰）
3
两张标签
等腰直角三角形
▼
两条独立的轴点击翻面
按角一张、按边一张
等腰也能是直角或钝角
完整名字两张都要报
4
不存在的组合
等边只能是锐角
▼
哪组合不了点击翻面
等边三角都是 60°
所以「等边钝角」「等边直角」都没有
一个三角形最多一个直角或钝角

再看到一个三角形，先问最大角过没过 90°，再数有几条边一样长。两张标签都贴好，名字才算叫全。
